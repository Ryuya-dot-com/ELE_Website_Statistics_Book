19.1 はじめに

英語教育の研究データには、しばしば地理的な構造が埋め込まれています。教育政策研究では、学力格差や教育機会の地域差を地図化し、その背後にある政策・資源配分・分離の構造を検討する仕事が蓄積してきました (Jang & Reardon, 2019; Reardon et al., 2019)。また社会言語学でも、言語変異の地理的集積や拡散を記述することは、方言地理学や dialectometry の中心課題です (Grieve, 2016; Labov et al., 2006)。たとえば、以下の場面を考えてみてください。

  1. 全国学力調査の結果を都道府県別に比較したい。どの地域の英語スコアが高く、どの地域が低いのでしょうか。単なる順位表ではなく、地図上に可視化すれば、地理的パターン（例: 都市圏に高スコアが集中、あるいは東西で傾向が異なる）が一目でわかります。
  2. 教員の英語力指標（TOEICスコア、英検取得率）の年次変化を追跡したい。7年間の変化は全国で一様なのでしょうか。それとも特定の地域だけが急速に改善（または停滞）しているのでしょうか。年ごとの地図を並べれば、時空間的なトレンドが浮かび上がります。
  3. 2021年に導入されたALT配置拡充施策の効果を評価したい。施策導入前と導入後で英語スコアはどう変化したのでしょうか。その変化は施策実施地域に限定されるのでしょうか、それとも隣接地域にも波及しているのでしょうか。

これらの問いに答えるには、数表やグラフだけでなく地図が不可欠です。そして地図を作るには、都道府県の「形」（境界線のポリゴンデータ）と分析データを結びつける技術が必要です。地図は単なる見栄えの改善ではなく、「どこに集積があるか」「どこが周囲から外れているか」「政策の変化がどこまで波及しているか」という仮説を立てるための分析装置です (Grieve, 2016; Lovelace et al., 2019)。

本章は、そのための基礎工事です。Rの sf パッケージを使って地理空間データを扱う方法を、都道府県別の英語教育指標データを題材に学びます。具体的には、形状データの取得、属性データとの結合、コロプレス図（塗り分け地図）の作成、パネルデータの整形までを最小限のコードで体験します。

ただし、地理空間データを扱うときは、地図が説得的に見える分だけ読み過ぎに注意が必要です。本章の単位は都道府県であり、地図に描かれる値は個々の学習者や学校ではなく、地域単位へ集計された値です。近い場所ほど似ている傾向があるという発想は Tobler の第一法則としてよく知られていますが (Tobler, 1970)、どの単位に集計するかによって結果が変わる MAUP（modifiable areal unit problem） も同時に生じます (Openshaw, 1984)。また、都道府県平均の相関から個人レベルの関係を直接推論することは、エコロジカルな誤謬につながります (Robinson, 1950)。したがって、本章の地図は「個人の英語力を説明する図」ではなく、「地域単位で観察された指標の空間分布を読む図」として扱います。

19.1.1 この章の到達目標

本章は以下の3つのパートで構成されています。

  • Part A（Section 3–6）: 地図を描く — 形状データの取得から、データ結合、コロプレス図、年次比較までを扱います。「都道府県別の英語スコアを地図上に描く」という目標を達成します。
  • Part B（Section 7–8）: パネルを整える — パネルデータ（都道府県×年）の整形、要約統計、品質チェックを扱います。次章の空間分析に必要なデータ構造を準備します。
  • Part C（Section 9–10）: 空間パターンを測る — Moran’s I による空間自己相関の初歩的な検定と、施策前後差分の可視化を扱います。次章（応用編）への橋渡しになります。

推奨: Part A を丁寧に読むことを推奨します。Part B はデータ整形の実務知識、Part C は次章の予習として活用してください。

読み終えると、少なくとも次の3点ができるようになります。第1に、「地図の形」と「分析用の数表」をどう結びつけるかが分かります。第2に、1年分のコロプレス図と複数年の比較地図を作り、地域差と年次変化を読み分けられるようになります。第3に、Moran’s I と LISA を使って、「見た目にまとまって見えるパターン」が偶然以上かどうかを、初歩的に判断できるようになります。

19.1.2 主なパッケージの役割

  • sf: 地理空間データの中核パッケージです。形状（ポリゴン・ポイント等）と属性データを一体化した「空間データフレーム」を扱います。
  • dplyr / tidyr: データの変換・結合・整形を担当します。sf オブジェクトに対しても dplyr の動詞（filter, mutate, left_join 等）がそのまま使えます。
  • ggplot2: 可視化を担当します。geom_sf() で地図を描画します。
  • classInt: コロプレス図の階級区分（分位点、等間隔、自然区分等）を計算します。
  • gt: 学術論文風の表を作成します。

本章では、sf によるベクタ地理データの扱い (Pebesma, 2018)、spdep による隣接・空間自己相関の基本 (R. Bivand, 2024; R. S. Bivand et al., 2013; R. S. Bivand & Wong, 2018)、leaflet によるインタラクティブ地図 (Cheng et al., 2024) という3本柱を、パッケージの公式ドキュメントと整合する範囲で入門向けに整理します。空間自己相関指標の実装比較については R. S. Bivand & Wong (2018) が、グローバル/ローカル指標の R/Python/GeoDa での挙動の違いを系統的に整理しており参照価値が高いです。

19.1.4 地図化する前に確認する3つの問い

コロプレス図を作る前に、少なくとも次の3点を確認してください。

  1. 単位は何か: 都道府県、市区町村、学校、個人のどのレベルのデータでしょうか。同じ現象でも、都道府県で集計した場合と学校単位で見た場合では、空間パターンが変わることがあります。これが MAUP の基本的な問題です (Openshaw, 1984)。
  2. 分母は何か: 件数、平均、割合、標準化得点のどれを地図化しているのでしょうか。受験者数や学校数が地域によって大きく違う場合、単純な件数や不安定な割合をそのまま塗り分けると、人口規模や標本サイズを地図化しているだけになることがあります。
  3. 誰について主張できるか: 都道府県平均の地図から、「その県の個々の学習者が高い／低い」とは言えません。個人差や学校差を論じたい場合は、個人・学校レベルのデータとマルチレベルモデルが必要です。

この章では、都道府県単位の記述・探索を目的にしています。したがって、地図を読むときの主語は「都道府県レベルの英語教育指標」であり、「個人の英語力」ではありません。この区別を明示しておくと、地図から因果や個人差まで一気に読み替えてしまう危険を避けられます。

19.2 分析の流れ

本章の作業は、以下のフローに沿って進みます。各ステップは前のステップの出力に依存しているため、順番に実行してください。

最初に都道府県ポリゴンなどの形状データを取得し、都道府県名の正規化（名寄せ）を行います。次に都道府県×年の指標データを作成し、left_join() で形状データと結合します。その後、最新年のコロプレス図と年次比較図（facet_wrap）を作成し、同時にパネル形式へ整形して要約表と品質チェックを実施します。整形後のデータに対して Moran’s I による空間自己相関と施策前後差分の可視化を行い、応用編での空間回帰へ接続します。

言い換えると、本章は「白地図を用意する → スコアを貼り付ける → 年ごとの変化を比べる → そのまとまりが偶然かを確かめる」という4段階です。コードの細部を一度に覚えようとするよりも、「今どの段階にいるのか」を意識しながら読むと理解しやすくなります。

19.2.2 「形状＋属性」の二重構造

地理空間分析のデータは、常に2つの要素から構成されます。

  1. 形状データ（geometry）: 都道府県の境界線を表すポリゴン。「どこにあるか」の情報。
  2. 属性データ（attributes）: 英語スコア、教員TOEIC、英検取得率などの数値。「何がどのくらいか」の情報。

この2つを left_join() で結合して初めて「地図上に色を塗る」ことができます。通常の回帰分析では属性データだけを扱いますが、空間分析では形状データが常に伴走する点が特徴です。

19.3 形状データの取得

19.3.1 sf オブジェクトとは

sf（Simple Features）パッケージは、地理空間データをRのデータフレームとして扱えるようにする仕組みです。通常のデータフレームに geometry という特殊な列が追加されているだけで、dplyr の関数がそのまま使えます。

さらに単純化すると、sf は「普段の表に、地図を描くための列が1本追加されたもの」です。Excel の表に住所列や都道府県列を持つのと似ていますが、geometry 列には文字列ではなくポリゴンそのものが入っている点が違います。この発想で捉えると、filter() や mutate() がそのまま使える理由が見えやすくなります。

sf を普通のデータフレームとの対比で理解する

# 通常のデータフレーム
tibble(pref = "東京都", score = 72.5)

# sf オブジェクト（+ geometry 列）
tibble(pref = "東京都", score = 72.5, geometry = <POLYGON(...)>)
  • sf は「データフレーム + 地理座標」と考えると理解しやすいです。既存のデータ操作の知識がそのまま活きます。
  • geometry 列は ggplot2 の geom_sf() が自動的に読み取り、地図を描画します。
  • 空間操作が不要な場面では st_drop_geometry() で geometry を外し、軽量なテーブルに戻せます。

19.3.2 形状データの取得（フォールバック付き）

日本の都道府県境界ポリゴンを取得します。パッケージの利用可能性は環境によって異なるため、3段階のフォールバックを設けています。

  1. jpndistrict: 日本専用パッケージです。高品質な都道府県境界を提供します。
  2. rnaturalearth: 世界の行政区画データです。日本の都道府県レベル（Admin-1）を取得できます。
  3. geodata（GADM）: 別のグローバルデータソース。

ここで理解すべき本筋は、「sf オブジェクトを取得し、st_crs() と geom_sf() で確認する」ことです。下の関数にあるフォールバック分岐は、章全体が環境依存で止まりにくくするための堅牢化コードであり、空間分析そのものの核心ではありません。

fetch_pref_sf_jpndistrict <- function() {
  if (!requireNamespace("jpndistrict", quietly = TRUE)) return(NULL)
  out <- tryCatch(jpndistrict::jpn_pref(quality = 40), error = function(e) NULL)
  if (!inherits(out, "sf")) return(NULL)
  out <- out |>
    st_transform(4326) |>
    dplyr::rename(pref_name = prefecture) |>
    dplyr::select(pref_name, geometry) |>
    sf::st_make_valid()
  attr(out, "shape_source") <- "jpndistrict::jpn_pref(quality = 40)"
  out
}

fetch_pref_sf_naturalearth <- function() {
  if (!requireNamespace("rnaturalearth", quietly = TRUE)) return(NULL)
  out <- tryCatch(rnaturalearth::ne_states(country = "Japan", returnclass = "sf"), error = function(e) NULL)
  if (!inherits(out, "sf")) return(NULL)
  out <- out |>
    dplyr::transmute(pref_name = name, geometry = geometry) |>
    st_transform(4326) |>
    sf::st_make_valid()
  attr(out, "shape_source") <- "rnaturalearth::ne_states(country = 'Japan')"

}

fetch_pref_sf_geodata <- function() {
  if (!requireNamespace("geodata", quietly = TRUE)) return(NULL)
  out <- tryCatch(geodata::gadm(country = "JPN", level = 1, path = tempdir()), error = function(e) NULL)
  if (is.null(out)) return(NULL)
  gd_sf <- sf::st_as_sf(out)
  name_col <- intersect(names(gd_sf), c("NAME_1", "NAME_1_", "VARNAME_1"))
  if (length(name_col) == 0) name_col <- names(gd_sf)[1]
  out <- gd_sf |>
    dplyr::transmute(pref_name = .data[[name_col[1]]], geometry = geometry) |>
    sf::st_make_valid() |>
    sf::st_transform(4326)
  attr(out, "shape_source") <- "geodata::gadm(country = 'JPN', level = 1)"
  out
}

CRS（座標参照系）とは

地球は球体ですが、コンピュータの画面は平面です。CRS は「球体上の位置を平面上の座標に変換する方法」を定義する規約です。

  • EPSG:4326（WGS84）: 緯度・経度の地理 CRS です。sf の表示確認やWeb地図との受け渡しでよく使います。
  • EPSG:3857（Web メルカトル）: 主にWeb地図表示用の CRS です。見た目の重ね合わせには便利ですが、距離や面積の計測そのものには向きません。
  • 地域に合った投影 CRS: 面積・距離を平面座標で扱いたいときに使います。日本全国を一括で測るときは、単一の EPSG を機械的に当てるのではなく、処理目的に応じて選びます。日本でよく使われる測地系として、JGD2011 (測地成果 2011, EPSG:6668 系) と JGD2000 (EPSG:4612 系) があります。国土地理院の基盤地図情報や e-Stat の境界データはこれらを採用していることが多く、研究で日本国内の距離・面積を厳密に測りたい場合は、平面直角座標系 (EPSG:6669–6687、19 系) や UTM 53/54N (EPSG:6691, 6688) など、対象地域に合致する投影系へ st_transform() で変換するのが標準的です。

sf の公式ドキュメントでも、st_crs() で現在の CRS を確認し、st_transform() で明示的に変換することが基本です (Pebesma, 2018)。最初に固定したい実務ルールとしては、「表示は 4326、計測は geodesic 計算か、研究地域に合った投影 CRS を明示して使う」と理解するのが安全です。

19.3.3 隣接の定義：Queen と Rook

地図を描くだけなら「隣接」を考える必要はありませんが、次章以降で空間自己相関や空間回帰を行う際に「誰が誰の隣人か」を定義する必要があります。ここでは3つの代表的な隣接定義を紹介します。

  • Queen 型: 辺または頂点を共有していれば隣接とみなします。チェスのクイーンが八方向に動けるイメージです。つながりが多く、空間的影響を広く捉えます。
  • Rook 型: 辺（境界線）を共有している場合だけ隣接とみなします。チェスのルークが上下左右に動くイメージです。Queen より厳格です。
  • k 近傍（kNN）: 各地域の重心から距離が近い順に k 個を隣接とします。島や飛地でも必ず隣接が定義でき、孤立ノードを回避できます。

英語教育研究での選択指針

  • 都道府県レベルの分析: 行政的な隣接を仮説にするなら Queen は扱いやすい出発点です。ただし、辺/頂点の共有が研究上の接触メカニズムを表しているとは限らないため、Rook、kNN、距離ベースの重みとの感度分析を行います。
  • 島嶼部を含む分析: 沖縄や離島を含む場合は kNN（例: k = 4–6）を併用し、孤立ノードを回避します。
  • 感度分析は必須: 主要な結論が隣接定義の選択で変わらないかを確認します（次章 Section 4 で詳述します）。

以下のコードは参照用です。次章で実際に使用しますが、ここでは概念の理解のために掲載します。

コード 
# Queen（既定は queen=TRUE）
nb_queen <- spdep::poly2nb(pref_sf, queen = TRUE)
lw_queen <- spdep::nb2listw(nb_queen, style = 'W')

# Rook（辺共有のみ）
nb_rook  <- spdep::poly2nb(pref_sf, queen = FALSE)
lw_rook  <- spdep::nb2listw(nb_rook,  style = 'W')

# k 近傍（例: k=6）。代表点は投影座標上で作ると警告が出にくい
pref_points <- pref_sf |>
  sf::st_transform(3857) |>
  sf::st_point_on_surface()
knn      <- spdep::knearneigh(pref_points, k = 6)
nb_knn   <- spdep::knn2nb(knn)
lw_knn   <- spdep::nb2listw(nb_knn, style = 'W')

nb と listw の違い

上のコードには nb と listw の2つのオブジェクトが登場します。

  • nb（隣接リスト）: 「都道府県Aの隣は B, C, D」という接続情報のみを持つオブジェクトです。重みはまだ付いていません。
  • listw（重み付き隣接）: nb に重みを付加したものです。style = 'W'（行標準化）は、各地域の重みの合計が1になるように調整します。

空間分析の関数（moran.test(), lagsarlm() 等）は listw を入力として要求します。nb をそのまま渡すと「not a listw object」というエラーが出るので注意してください。

19.4 都道府県名の正規化（名寄せ）

形状データの都道府県名と、分析対象の指標データの都道府県名は、そのままでは一致しないことがあります。全角/半角、余分な空白、末尾の「都・道・府・県」の有無といった表記の揺れが原因です。以下の norm_pref() 関数は、この揺れを吸収して名寄せを可能にします。

コード 
# 正規化関数：全角/半角・空白・末尾の都/道/府/県の扱い
norm_pref <- function(x){
  x |>
    stringi::stri_trans_nfkc() |>
    stringr::str_replace_all("\\s+", "") |>
    stringr::str_replace("(東京都|北海道|京都府|大阪府)$", "") |>
    stringr::str_replace("県$", "")
}

# 形状側の正規化キー
jpn_key <- pref_sf |>
  st_drop_geometry() |>
  transmute(pref_name,
            pref_key = norm_pref(pref_name))

本章のRコードでは |> （ネイティブパイプ）を多用します。これは「左辺の結果を右辺の関数の第1引数に順番に渡す」記法です。norm_pref() の中身も、(1) NFKC正規化（全角/半角の統一）→ (2) 空白除去 → (3) 「東京都/北海道/京都府/大阪府」の除去 → (4) 末尾の「県」の除去、という処理を上から下へ読めば理解できます。名寄せで重要なのは、表記ゆれを吸収してから anti_join() で未対応の都道府県を洗い出すことです。実データに旧字体や略称がある場合は、norm_pref() に辞書置換を追加します。

19.5 ダミーデータの作成（英語教育指標）

19.5.1 分析シナリオ

本章では、2018–2024年の7年間・47都道府県について、eng_score（英語学力複合スコア）、teacher_toeic（教員の平均TOEIC）、eiken_rate（英検準2級以上取得率）を追跡するシミュレーションデータを使います。ここでは単に「県ごとの平均が違う」だけではなく、空間クラスタと施策波及が見えるように設計します。具体的には、首都圏と近畿圏に高値が集まりやすく、北日本にやや低い集積があり、2021年以降は首都圏の一部県で ALT 配置拡充施策が始まり、近隣県にも弱いスピルオーバーが起こるという設定です。こうした「地域差の地図化」と「政策文脈との接続」は、教育政策研究で学力や SES 勾配の地域差を読むときにも中心的な発想です (Jang & Reardon, 2019; Reardon et al., 2019)。

シミュレーションを使う理由は、地図・Moran’s I・前後差分が何を拾うはずかを先に知っておくためです。真の空間パターンを埋め込んでおけば、あとで得られる結果が「コードの誤り」なのか「データの性質」なのかを切り分けやすくなります。

コード 
set.seed(2024)
years <- 2018:2024

sapporo_hub <- sf::st_sfc(sf::st_point(c(141.3545, 43.0618)), crs = 4326)

pref_features <- tibble::tibble(
  pref_name = pref_sf$pref_name,
  lon = pref_coords[, "X"],
  lat = pref_coords[, "Y"],
  dist_tokyo_km = as.numeric(units::set_units(sf::st_distance(pref_points, tokyo_hub), "km")),
  dist_osaka_km = as.numeric(units::set_units(sf::st_distance(pref_points, osaka_hub), "km")),
  dist_sapporo_km = as.numeric(units::set_units(sf::st_distance(pref_points, sapporo_hub), "km"))
) |>
  mutate(
    hot_kanto = exp(-(dist_tokyo_km / 260)^2),
    hot_kansai = exp(-(dist_osaka_km / 220)^2),
    cold_north = exp(-(dist_sapporo_km / 280)^2),
    treat_core = dist_tokyo_km <= 220,
    spillover = dist_tokyo_km > 220 & dist_tokyo_km <= 360
  )

pref_random <- tibble::tibble(
  pref_name = pref_features$pref_name,
  pref_intercept = rnorm(nrow(pref_features), 0, 1.8),
  toeic_random = rnorm(nrow(pref_features), 0, 18),
  eiken_random = rnorm(nrow(pref_features), 0, 0.02)
)

pref_panel <- tidyr::expand_grid(pref_name = pref_sf$pref_name, year = years) |>
  left_join(pref_features, by = "pref_name") |>
  left_join(pref_random, by = "pref_name") |>
  mutate(
    post = year >= 2021,
    policy_effect = if_else(post & treat_core, 3.0, 0) + if_else(post & spillover, 1.4, 0),
    common_trend = 0.55 * (year - min(years)),
    eng_score = round(
      55 + 7.5 * hot_kanto + 5.5 * hot_kansai - 4.5 * cold_north +
        pref_intercept + common_trend + policy_effect +
        rnorm(n(), 0, 1.8),
      1
    ),
    teacher_toeic = pmax(
      round(
        635 + 38 * hot_kanto + 22 * hot_kansai - 18 * cold_north +
          toeic_random + 4.5 * (year - min(years)) + 6 * policy_effect +
          rnorm(n(), 0, 16),
        0
      ),
      350
    ),
    eiken_rate = round(
      pmin(
        pmax(
          0.26 + 0.11 * hot_kanto + 0.07 * hot_kansai - 0.05 * cold_north +
            eiken_random + 0.012 * (year - min(years)) + 0.01 * policy_effect +
            rnorm(n(), 0, 0.02),
          0.05
        ),
        0.95
      ),
      3

19.5.2 結合前のミスマッチ検出

形状データと指標データを結合する前に、名寄せの成功を検証します。anti_join() は「一方にあるが他方にない」レコードを抽出する関数で、ミスマッチの発見に威力を発揮します。

anti_join() は、Excel の照合で「対応が取れなかった行だけを抜き出す」操作に近いと考えると分かりやすいです。ここで未一致が残っていると、あとで地図に NA が大量に出るので、必ずこの段階で潰しておきます。

コード

19.6 結合とコロプレス図

19.6.1 形状＋最新年指標の結合

コード 
pref_map <- pref_sf |>
  left_join(pref_latest, by = 'pref_name')

left_join(A, B, by = "key") は、「Aの行をすべて残したまま、キーが一致するBの列を横に追加する」操作です。ここでは形状データ pref_sf を左側に置くことで、47都道府県のポリゴンを落とさずに保持できます。もし指標データ側に欠けがあれば NA が入るので、先ほどの anti_join() による事前確認が効いてきます。

表計算ソフトに慣れているなら、left_join() は XLOOKUP や VLOOKUP で列を追加する操作にかなり近いです。ただし地図では、左側に形状データを置くことが特に重要です。逆にすると「値はあるが形がない」状態になり、地図として描けなくなります。

19.6.2 コロプレス図（塗り分け地図）

コロプレス図は、各地域を数値の大小に応じた色で塗り分ける地図です。英語教育研究では、全国の指標を俯瞰的に把握するための基本ツールとなります。

19.8 空間自己相関の初歩（Moran’s I）

19.8.1 なぜ空間自己相関を考える必要があるのか

コロプレス図を眺めて「高スコアの都道府県が集まっているように見える」と感じたとしても、それだけでは科学的な主張にはなりません。ランダムなデータでも、たまたまそう見えるパターンが出現することがあります。Moran’s I は、観察された空間パターンが偶然で説明できるかどうかを統計的に検定する指標で、グローバルな空間自己相関を測る最も基本的な統計量です (R. Bivand, 2024; Moran, 1950)。

直感的には、Moran’s I はPearson の相関係数 \(r\) の空間版です。

  • Pearson の \(r\): 2つの変数 \(X\) と \(Y\) の間の線形関連の強さを測る。
  • Moran’s \(I\): ある地点の値と、その隣接地域の加重平均値との間の線形関連を測る。

\(I > 0\) ならば、似た値が近接に集まる傾向（正の空間自己相関）。\(I < 0\) ならば、異なる値が隣り合う傾向。\(I \approx 0\) ならば、空間的にランダムな分布です。

ここでのポイントは、「高いか低いか」ではなく「似たものどうしが近くにあるか」を測っていることです。たとえば、全国平均が高くても低くても、地理的に入り混じっていれば Moran’s I は大きくなりません。逆に、値そのものが中程度でも、似た県が近くに集まれば Moran’s I は正になります。

英語教育研究で Moran’s I を見る理由は2つあります。第1に、空間自己相関が強いと通常の OLS が仮定する「観測の独立」が崩れ、標準誤差や p 値の解釈が甘くなる可能性があります。第2に、もし高い英語力や高い教員 TOEIC が地理的に集まっているなら、その背景に地域経済、教員配置、学習資源、近隣自治体からの波及といった実質的メカニズムを考える必要があります。つまり Moran’s I は、統計的診断であると同時に、次の研究課題を立てる入口でもあります (R. S. Bivand et al., 2013; Lovelace et al., 2019)。この発想は社会言語学でも同様で、地域変異の研究では「どこで似た発音や語法がまとまって現れるか」を地図化すること自体が理論的関心の一部です (Grieve, 2016; Labov et al., 2006)。

19.8.4 ローカル Moran（LISA クラスタ図）

グローバル Moran’s I は「全体として空間自己相関があるか」を示しますが、「どの都道府県がクラスタの一部か」は教えてくれません。ローカル Moran’s I（LISA: Local Indicators of Spatial Association）は、各地域を以下の4タイプに分類するための局所統計量です (Anselin, 1995)。

  • High-High（HH）: 自身も隣接も高い。「ホットスポット」。
  • Low-Low（LL）: 自身も隣接も低い。「コールドスポット」。
  • High-Low（HL）: 自身は高いが隣接は低い。空間的アウトライヤ。
  • Low-High（LH）: 自身は低いが隣接は高い。空間的アウトライヤ。
コード 
# ローカル Moran（permutation ベース）
loc <- spdep::localmoran_perm(
  dat_moran$eng_score,
  lw_moran,
  nsim = 999,
  zero.policy = TRUE,
  alternative = "two.sided",
  iseed = 2024
)
dat_moran$Ii <- loc[, 'Ii']
p_perm <- loc[, "Pr(z != E(Ii)) Sim"]

z      <- as.numeric(scale(dat_moran$eng_score))
lag_z  <- spdep::lag.listw(lw_moran, z, zero.policy = TRUE)

cluster <- ifelse(p_perm >= 0.05, 'Not Sig',
           ifelse(z>0 & lag_z>0, 'High-High',
           ifelse(z<0 & lag_z<0, 'Low-Low',
           ifelse(z>0 & lag_z<0, 'High-Low', 'Low-High'))))

dat_moran$cluster <- factor(cluster, levels = c('High-High','Low-Low','High-Low','Low-High','Not Sig'))

ggplot(dat_moran) +
  geom_sf(aes(fill = cluster), color = 'white') +
  scale_fill_manual(
    values = c('High-High'='#d73027','Low-Low'='#4575b4','High-Low'='#fdae61','Low-High'='#74add1','Not Sig'='grey90'),
    drop = FALSE
  ) +
  theme_geo() +
  labs(title = "LISA Cluster Map (permutation p < .05)", fill = 'Cluster')

読み方: 赤い地域（HH）は英語力のホットスポット、青い地域（LL）はコールドスポットです。オレンジや水色は、周囲と逆方向にずれた空間的アウトライヤです。今回は localmoran_perm() による permutation ベースの p 値を使っており、解析的近似よりも解釈の入口として扱いやすい形にしています。ただし、LISA は都道府県ごとに複数の局所検定を並べるため、p < .05 をそのまま「確定的証拠」と読むのではなく、探索的なクラスタ候補として扱うのが安全です (Anselin, 1995; R. Bivand, 2024)。教育政策研究でも社会言語学でも、局所クラスタ図は「さらに掘るべき場所」を見つけるための道具であり、単独で因果や境界の実在を確定するものではありません (Grieve, 2016; Reardon et al., 2019)。

最初に見る順番は、(1) 赤と青の大きな塊がどこにあるか、(2) 灰色が多いか少ないか、(3) オレンジや水色の外れた県がどこにあるか、の3つです。赤や青の塊は「まとまり」、灰色は「今回は局所統計量がはっきりしなかった場所」、オレンジや水色は「周囲とずれている場所」と読むと混乱しにくくなります。

この図でわかること: どの地域が局所的なホットスポット・コールドスポットかという点です。

この図だけではわからないこと: そのクラスタを生んだ原因や、境界が本当に固定的かどうかという点です。

19.9 時空間パネル：施策前後差分

この節では、パネルデータ（都道府県×年）を活用して、ある施策の前後で指標がどう変化したかを可視化します。次章で扱うDID（差の差法）の準備として、まず視覚的に変化のパターンを把握することが目的です。

19.9.1 伸び率の時系列

コード 
growth <- pref_panel |>

この折れ線は、施策の因果効果を推定する図ではなく、都道府県を同じ重みで平均した伸び率がどの年に大きかったかを点検するための図です。2021 年以降に平均伸び率が少し上向くなら、後で描く前後差分地図のパターンと整合的かを見比べられます。一方で、全国的な景気や学習指導要領の変更でも同じ形は出るため、この図だけで施策評価はできません。

したがって、この図の役割は「施策が効いた」と結論づけることではなく、「2021 年以降に何か全体的な変化がありそうか」を先に眺めることです。地図の前に折れ線を見ることで、都道府県平均の変化と地域差の変化を混同しにくくなります。

この図でわかること: 都道府県平均として見た変化の山や谷の位置です。

この図だけではわからないこと: どの地域がその変化を主に担っているかという点です。

19.9.2 施策前後差分の地図

ここで見たいのは、単に「どこが上がったか」ではなく、「上昇が地理的にまとまっているか」です。もし施策中心県の周囲にも同方向の変化が見えるなら、空間的な波及を疑う出発点になります。

コード 
policy_year <- 2021
prepost <- pref_panel |>
  mutate(period = if_else(year < policy_year, 'pre', 'post')) |>
  group_by(pref_name, period) |>
  summarise(mean_score = mean(eng_score, na.rm = TRUE), .groups = 'drop') |>
  tidyr::pivot_wider(names_from = period, values_from = mean_score) |>
  mutate(diff_post_pre = post - pre)

map_diff <- pref_sf |>
  left_join(prepost, by = 'pref_name')

ggplot(map_diff) +
  geom_sf(aes(fill = diff_post_pre), color = 'white') +
  scale_fill_gradient2(low = '#4575b4', mid = 'white', high = '#d73027', midpoint = 0,
                       name = 'Diff (Post - Pre)') +
  theme_geo() +
  labs(title = paste0('Pre-Post Score Difference (Policy Year: ', policy_year, ')'))

読み方: 赤い地域は施策導入年以降にスコアが上昇、青い地域は低下した都道府県です。ここでは year < 2021 を事前期間、year >= 2021 を事後期間として、DID 側の post 定義と揃えています。このシミュレーションでは首都圏の施策中心県とその近隣県に正の差分が現れるように作っているので、その空間的広がりが視覚的に見えるかを確認してください。ただし、この地図だけでは施策効果は判定できません。全国トレンド（時間固定効果）や各都道府県固有の水準差（地域固定効果）を統制した比較が必要であり、次章では DID の枠組みでそこを扱います。因果推定の観点から見ると、前後差分はあくまで記述的な「変化量」であり、対照群や設計上の仮定なしに因果効果へ読み替えることはできません (Angrist & Pischke, 2009)。教育政策研究でも、州や学区の文脈差が大きいため、見かけの地図パターンをそのまま政策効果と呼ばないことが重要です (Jang & Reardon, 2019)。

まず「赤がどこに集まっているか」を見れば十分です。その後で、「その赤い県はもともと高かったのか、もともと低かったのか」「近隣県にも同じ方向の変化があるか」を順に確かめると、単なる前後差と空間的波及の違いが見えやすくなります。

この図でわかること: 変化量がどこに集中しているかという点です。

この図だけではわからないこと: その変化が施策の因果効果か、全国トレンドや他の要因かという点です。

19.10 インタラクティブ地図（leaflet）

ここまでの地図はすべて静的な画像でした。研究発表やデータ探索では、マウス操作で拡大・縮小やホバー情報表示ができるインタラクティブ地図が有用です。

ただし、leaflet は「厳密な比較」より「探索」に向いています。複数年を並べて色を見比べるのは静的図の方が得意で、leaflet は個別の県名や値をその場で確かめたいときに力を発揮します。

コード 
pacman::p_load(leaflet)
pal <- leaflet::colorBin('Blues', domain = pref_map$eng_score, bins = 5)
leaflet::leaflet(pref_map) |>
  leaflet::addProviderTiles(leaflet::providers$CartoDB.Positron) |>
  leaflet::addPolygons(fillColor = ~pal(eng_score), color = '#777', weight = 1,
              popup = ~paste0(pref_name, '<br>Score: ', eng_score)) |>
  leaflet::addLegend(pal = pal, values = ~eng_score, title = 'English Score')

leaflet() の公式ドキュメントでも、data に sf オブジェクトを直接渡し、addProviderTiles() で背景タイル、addPolygons() でポリゴン、addLegend() で凡例を重ねるのが基本パターンです (Cheng et al., 2024)。~eng_score のようなフォーミュラ記法は、ggplot2 の aes(fill = eng_score) に近い役割だと理解すると迷いにくくなります。なお、leaflet は既定で Web 地図用 CRS を使うので、公式 docs にある通り、CRS を自分で変えるのは意味が分かっている場合に限るのが安全です。このコードは eval: false なので、実際に試すときだけ eval: true に変更してください。

静的地図と leaflet の違いは、役割で分けると分かりやすいです。論文や本文では比較しやすい静的地図、探索や発表準備では県名や値をその場で確認しやすい leaflet、という使い分けが基本になります。

この図でわかること: 個々の県名や値を対話的に確認できることです。

この図だけではわからないこと: 年ごとの厳密な比較や、論文用の再現しやすい図示です。

19.11 トラブルシューティング

19.11.1 データ結合の問題

  • left_join() 後に値が全部 NA: キー列の表記ゆれが原因です。norm_pref() で両側を正規化し、anti_join() でミスマッチを検出します。
  • 結合後に行数が増えた: キー列に重複があります。count(pref_name, year) で1行以上のレコードがないか確認します。
  • 47都道府県に満たない: 形状データまたは指標データで一部の都道府県が欠損しています。n_distinct(pref_name) で確認します。

19.11.2 形状データと CRS の問題

  • 点とポリゴンの場所が合わない: CRS が揃っていません。st_crs() で両方を確認し、st_transform() で統一します。
  • 面積・距離がおかしい: Web表示用 CRS をそのまま計測に使っている可能性があります。sf では geodesic 計算を使うか、研究地域に合った投影 CRS を明示してから平面距離・面積を計算します。
  • 無効ジオメトリ（self-intersection）: st_is_valid() で検出し、st_make_valid() で修復します。

19.11.3 可視化の問題

  • 年次比較で色の印象がブレる: limits を固定していません。scale_fill_viridis_c(limits = global_limits) で全パネル共通のスケールを指定します。
  • geom_sf() が重い/描画が遅い: 高解像度の形状データを使用しています。試作段階では st_simplify() で簡略化するか、低解像度形状を使います。
  • 日本語が文字化け（豆腐化）: YAML の mainfont や R セッションのロケール（Sys.setlocale()）を見直します。Noto Serif JP / Noto Sans JP を推奨します。

19.11.4 パネル整形の問題

  • object 'pref_map' not found: チャンクの実行順序が原因です。Quarto で上から順に実行されていることを確認します。
  • Inf や NaN が混入: 伸び率のゼロ割です。if_else(prev == 0, NA, ...) でガードするか、対数差分を使います。
  • 欠損年が暗黙に無視されている: complete() で明示的にパネルの格子を作成します。

19.11.5 解釈の問題

  • 都道府県平均を個人差として読んでいる: 都道府県単位の地図は地域平均の地図です。個人や学校の分布を直接示すものではありません。個人差を論じる場合は、個人・学校レベルのデータと階層構造を明示したモデルが必要です。
  • 件数と率を混同している: 受験者数や学校数のような件数は、人口規模や学校規模の地図になりやすいです。地域間比較では、平均、割合、人口当たり率、標準化得点など、分母を明示できる指標を優先します。
  • 行政境界を自然な境界として読んでいる: 都道府県境界は分析上の単位であり、学習資源、通学圏、教員移動、言語変化の境界と常に一致するわけではありません。境界の選び方を変えると結果が変わる可能性があります。

19.11.6 空間分析の問題

  • regions with no neighbours: 島嶼部で孤立ノードが発生しています。kNN の k を引き上げるか、距離閾値で接続します。
  • not a listw object: nb を直接渡しています。nb2listw(nb, style = 'W') で変換します。
  • sfdep と spdep の関数名の違いで混乱: 本書では spdep を基本パッケージとして使用します。sfdep::local_moran_perm 等を使いたい場合は別途インストールが必要です。

19.11.7 提出前チェックリスト

  • anti_join() の結果が 0 件か（名寄せ成功の確認）
  • st_crs() が揃っているか（CRS の統一）
  • ファセット比較でカラースケールが共通化されているか
  • st_is_valid() で無効ジオメトリがないか
  • パネルの行数 = 都道府県数 × 年数 ですか
  • 地図化した値の単位・分母・分類方法を図注に書いていますか
  • 都道府県平均から個人レベルの主張へ飛躍していませんか

19.12 次の一歩（応用編への橋渡し）

本入門では、形状の取得→名寄せ→結合→コロプレス→パネル整形→Moran’s I の初歩までを体験しました。データの読み込みから地図描画、パネルの品質管理まで、空間分析の「基礎工事」が完成しています。

次章（第15章: 応用編）では、この基礎の上に分析的なツールキットを構築します。

  • 空間重みの厳密な構築と感度分析: Queen/Rook/kNN の比較、結果の頑健性の検証を扱います。
  • 空間自己相関の厳密化: モンテカルロ検定、LISA の FDR 補正（多重比較調整）、Moran 散布図を扱います。
  • 空間回帰モデル: OLS の残差診断 → LM 検定 → SAR/SEM の選択 → インパクト分解（直接・間接・総効果）へ進みます。
  • 施策評価と DID: 固定効果 DID、クラスタ標準誤差、空間スピルオーバーと SUTVA を確認します。
  • 空間平滑化と発展トピック: ノイズ抑制、ベイズ空間モデル、GWR を紹介します。

本章でデータの準備と基礎的な可視化を習得したことで、応用編の分析手法にスムーズに進む準備が整っています。

19.12.1 実データに置き換えるとき

本章のダミーデータを実データに差し替えるときは、列名・単位・集計レベル（都道府県か市区町村か）が一致しているかを最初に確認します。次に、指標定義や集計ルールの変更年がないかを注釈で管理します。名寄せでは norm_pref() に実データ固有の表記ゆれを追加し、都道府県名だけでなく市区町村コードや学校コードのような正式キーが使えるならそちらを優先します。実データでは set.seed() 自体は不要ですが、欠測補完やサンプリングを含む前処理をするなら再現性のために乱数種を明示しておくと安全です。

## はじめに

英語教育の研究データには、しばしば**地理的な構造**が埋め込まれています。教育政策研究では、学力格差や教育機会の地域差を地図化し、その背後にある政策・資源配分・分離の構造を検討する仕事が蓄積してきました [@reardon2019geography; @jang2019states]。また社会言語学でも、言語変異の地理的集積や拡散を記述することは、方言地理学や dialectometry の中心課題です [@labov2006atlas; @grieve2016regional]。たとえば、以下の場面を考えてみてください。

1. **全国学力調査の結果を都道府県別に比較したい**。どの地域の英語スコアが高く、どの地域が低いのでしょうか。単なる順位表ではなく、地図上に可視化すれば、地理的パターン（例: 都市圏に高スコアが集中、あるいは東西で傾向が異なる）が一目でわかります。
2. **教員の英語力指標（TOEICスコア、英検取得率）の年次変化を追跡したい**。7年間の変化は全国で一様なのでしょうか。それとも特定の地域だけが急速に改善（または停滞）しているのでしょうか。年ごとの地図を並べれば、時空間的なトレンドが浮かび上がります。
3. **2021年に導入されたALT配置拡充施策の効果を評価したい**。施策導入前と導入後で英語スコアはどう変化したのでしょうか。その変化は施策実施地域に限定されるのでしょうか、それとも隣接地域にも波及しているのでしょうか。

これらの問いに答えるには、**数表やグラフだけでなく地図が不可欠**です。そして地図を作るには、都道府県の「形」（境界線のポリゴンデータ）と分析データを結びつける技術が必要です。地図は単なる見栄えの改善ではなく、「どこに集積があるか」「どこが周囲から外れているか」「政策の変化がどこまで波及しているか」という仮説を立てるための分析装置です [@lovelace2019; @grieve2016regional]。

本章は、そのための**基礎工事**です。Rの `sf` パッケージを使って地理空間データを扱う方法を、都道府県別の英語教育指標データを題材に学びます。具体的には、形状データの取得、属性データとの結合、コロプレス図（塗り分け地図）の作成、パネルデータの整形までを最小限のコードで体験します。

ただし、地理空間データを扱うときは、地図が説得的に見える分だけ読み過ぎに注意が必要です。本章の単位は都道府県であり、地図に描かれる値は個々の学習者や学校ではなく、地域単位へ集計された値です。近い場所ほど似ている傾向があるという発想は Tobler の第一法則としてよく知られていますが [@tobler1970]、どの単位に集計するかによって結果が変わる **MAUP（modifiable areal unit problem）** も同時に生じます [@openshaw1984]。また、都道府県平均の相関から個人レベルの関係を直接推論することは、エコロジカルな誤謬につながります [@robinson1950]。したがって、本章の地図は「個人の英語力を説明する図」ではなく、「地域単位で観察された指標の空間分布を読む図」として扱います。

### この章の到達目標

本章は以下の3つのパートで構成されています。

- **Part A（Section 3--6）: 地図を描く** --- 形状データの取得から、データ結合、コロプレス図、年次比較までを扱います。「都道府県別の英語スコアを地図上に描く」という目標を達成します。
- **Part B（Section 7--8）: パネルを整える** --- パネルデータ（都道府県×年）の整形、要約統計、品質チェックを扱います。次章の空間分析に必要なデータ構造を準備します。
- **Part C（Section 9--10）: 空間パターンを測る** --- Moran's I による空間自己相関の初歩的な検定と、施策前後差分の可視化を扱います。次章（応用編）への橋渡しになります。

**推奨**: Part A を丁寧に読むことを推奨します。Part B はデータ整形の実務知識、Part C は次章の予習として活用してください。

読み終えると、少なくとも次の3点ができるようになります。第1に、「地図の形」と「分析用の数表」をどう結びつけるかが分かります。第2に、1年分のコロプレス図と複数年の比較地図を作り、地域差と年次変化を読み分けられるようになります。第3に、Moran's I と LISA を使って、「見た目にまとまって見えるパターン」が偶然以上かどうかを、初歩的に判断できるようになります。

### 地図化する前に確認する3つの問い

コロプレス図を作る前に、少なくとも次の3点を確認してください。

1. **単位は何か**: 都道府県、市区町村、学校、個人のどのレベルのデータでしょうか。同じ現象でも、都道府県で集計した場合と学校単位で見た場合では、空間パターンが変わることがあります。これが MAUP の基本的な問題です [@openshaw1984]。
2. **分母は何か**: 件数、平均、割合、標準化得点のどれを地図化しているのでしょうか。受験者数や学校数が地域によって大きく違う場合、単純な件数や不安定な割合をそのまま塗り分けると、人口規模や標本サイズを地図化しているだけになることがあります。
3. **誰について主張できるか**: 都道府県平均の地図から、「その県の個々の学習者が高い／低い」とは言えません。個人差や学校差を論じたい場合は、個人・学校レベルのデータとマルチレベルモデルが必要です。

この章では、都道府県単位の記述・探索を目的にしています。したがって、地図を読むときの主語は「都道府県レベルの英語教育指標」であり、「個人の英語力」ではありません。この区別を明示しておくと、地図から因果や個人差まで一気に読み替えてしまう危険を避けられます。

## 分析の流れ

本章の作業は、以下のフローに沿って進みます。各ステップは前のステップの出力に依存しているため、順番に実行してください。

最初に都道府県ポリゴンなどの形状データを取得し、都道府県名の正規化（名寄せ）を行います。次に都道府県×年の指標データを作成し、`left_join()` で形状データと結合します。その後、最新年のコロプレス図と年次比較図（`facet_wrap`）を作成し、同時にパネル形式へ整形して要約表と品質チェックを実施します。整形後のデータに対して Moran's I による空間自己相関と施策前後差分の可視化を行い、応用編での空間回帰へ接続します。

言い換えると、本章は「白地図を用意する → スコアを貼り付ける → 年ごとの変化を比べる → そのまとまりが偶然かを確かめる」という4段階です。コードの細部を一度に覚えようとするよりも、「今どの段階にいるのか」を意識しながら読むと理解しやすくなります。

### 「形状＋属性」の二重構造

地理空間分析のデータは、常に2つの要素から構成されます。

1. **形状データ（geometry）**: 都道府県の境界線を表すポリゴン。「どこにあるか」の情報。
2. **属性データ（attributes）**: 英語スコア、教員TOEIC、英検取得率などの数値。「何がどのくらいか」の情報。

この2つを `left_join()` で結合して初めて「地図上に色を塗る」ことができます。通常の回帰分析では属性データだけを扱いますが、空間分析では形状データが常に伴走する点が特徴です。

## 形状データの取得

### sf オブジェクトとは

`sf`（Simple Features）パッケージは、地理空間データをRのデータフレームとして扱えるようにする仕組みです。通常のデータフレームに `geometry` という特殊な列が追加されているだけで、`dplyr` の関数がそのまま使えます。

さらに単純化すると、`sf` は「**普段の表に、地図を描くための列が1本追加されたもの**」です。Excel の表に住所列や都道府県列を持つのと似ていますが、`geometry` 列には文字列ではなくポリゴンそのものが入っている点が違います。この発想で捉えると、`filter()` や `mutate()` がそのまま使える理由が見えやすくなります。

#### sf を普通のデータフレームとの対比で理解する

```r
# 通常のデータフレーム
tibble(pref = "東京都", score = 72.5)

# sf オブジェクト（+ geometry 列）
tibble(pref = "東京都", score = 72.5, geometry = <POLYGON(...)>)
```

- `sf` は「データフレーム + 地理座標」と考えると理解しやすいです。既存のデータ操作の知識がそのまま活きます。
- `geometry` 列は `ggplot2` の `geom_sf()` が自動的に読み取り、地図を描画します。
- 空間操作が不要な場面では `st_drop_geometry()` で `geometry` を外し、軽量なテーブルに戻せます。

### 形状データの取得（フォールバック付き）

日本の都道府県境界ポリゴンを取得します。パッケージの利用可能性は環境によって異なるため、3段階のフォールバックを設けています。

1. **jpndistrict**: 日本専用パッケージです。高品質な都道府県境界を提供します。
2. **rnaturalearth**: 世界の行政区画データです。日本の都道府県レベル（Admin-1）を取得できます。
3. **geodata（GADM）**: 別のグローバルデータソース。

ここで理解すべき本筋は、「`sf` オブジェクトを取得し、`st_crs()` と `geom_sf()` で確認する」ことです。下の関数にあるフォールバック分岐は、章全体が環境依存で止まりにくくするための**堅牢化コード**であり、空間分析そのものの核心ではありません。

ここでの成功条件は単純です。`pref_sf` が 47 都道府県を含む `sf` オブジェクトとして得られ、白地図がきちんと描ければ先へ進めます。どのパッケージ経由で取得したかよりも、「地図の形が壊れていないか」「CRS が読めるか」を確かめることの方が重要です。

```{r}
#| eval: true

fetch_pref_sf_jpndistrict <- function() {
  if (!requireNamespace("jpndistrict", quietly = TRUE)) return(NULL)
  out <- tryCatch(jpndistrict::jpn_pref(quality = 40), error = function(e) NULL)
  if (!inherits(out, "sf")) return(NULL)
  out <- out |>
    st_transform(4326) |>
    dplyr::rename(pref_name = prefecture) |>
    dplyr::select(pref_name, geometry) |>
    sf::st_make_valid()
  attr(out, "shape_source") <- "jpndistrict::jpn_pref(quality = 40)"
  out
}

fetch_pref_sf_naturalearth <- function() {
  if (!requireNamespace("rnaturalearth", quietly = TRUE)) return(NULL)
  out <- tryCatch(rnaturalearth::ne_states(country = "Japan", returnclass = "sf"), error = function(e) NULL)
  if (!inherits(out, "sf")) return(NULL)
  out <- out |>
    dplyr::transmute(pref_name = name, geometry = geometry) |>
    st_transform(4326) |>
    sf::st_make_valid()
  attr(out, "shape_source") <- "rnaturalearth::ne_states(country = 'Japan')"
  out
}

fetch_pref_sf_geodata <- function() {
  if (!requireNamespace("geodata", quietly = TRUE)) return(NULL)
  out <- tryCatch(geodata::gadm(country = "JPN", level = 1, path = tempdir()), error = function(e) NULL)
  if (is.null(out)) return(NULL)
  gd_sf <- sf::st_as_sf(out)
  name_col <- intersect(names(gd_sf), c("NAME_1", "NAME_1_", "VARNAME_1"))
  if (length(name_col) == 0) name_col <- names(gd_sf)[1]
  out <- gd_sf |>
    dplyr::transmute(pref_name = .data[[name_col[1]]], geometry = geometry) |>
    sf::st_make_valid() |>
    sf::st_transform(4326)
  attr(out, "shape_source") <- "geodata::gadm(country = 'JPN', level = 1)"
  out
}

load_pref_sf <- function(){
  pref_sf <- fetch_pref_sf_jpndistrict()
  if (!is.null(pref_sf)) return(pref_sf)

  pref_sf <- fetch_pref_sf_naturalearth()
  if (!is.null(pref_sf)) return(pref_sf)

  pref_sf <- fetch_pref_sf_geodata()
  if (!is.null(pref_sf)) return(pref_sf)

  stop("都道府県ポリゴンの取得に失敗しました。'jpndistrict'、'rnaturalearth'、'geodata' の利用可能性をご確認ください。")
}

# 実境界のみを使用（ダミーhexには絶対フォールバックしない）

shape_source <- attr(pref_sf, "shape_source")

  stop("都道府県ポリゴンが47件ではありません。取得元・名称列・境界データの版を確認してください。")
}
```

#### CRS（座標参照系）とは

地球は球体ですが、コンピュータの画面は平面です。CRS は「球体上の位置を平面上の座標に変換する方法」を定義する規約です。

- **EPSG:4326（WGS84）**: 緯度・経度の地理 CRS です。`sf` の表示確認やWeb地図との受け渡しでよく使います。
- **EPSG:3857（Web メルカトル）**: 主にWeb地図表示用の CRS です。見た目の重ね合わせには便利ですが、距離や面積の計測そのものには向きません。
- **地域に合った投影 CRS**: 面積・距離を平面座標で扱いたいときに使います。日本全国を一括で測るときは、単一の EPSG を機械的に当てるのではなく、処理目的に応じて選びます。日本でよく使われる測地系として、**JGD2011 (測地成果 2011, EPSG:6668 系)** と **JGD2000 (EPSG:4612 系)** があります。国土地理院の基盤地図情報や e-Stat の境界データはこれらを採用していることが多く、研究で日本国内の距離・面積を厳密に測りたい場合は、平面直角座標系 (EPSG:6669–6687、19 系) や UTM 53/54N (EPSG:6691, 6688) など、対象地域に合致する投影系へ `st_transform()` で変換するのが標準的です。

`sf` の公式ドキュメントでも、`st_crs()` で現在の CRS を確認し、`st_transform()` で明示的に変換することが基本です [@pebesma2018]。**最初に固定したい実務ルール**としては、「表示は 4326、計測は geodesic 計算か、研究地域に合った投影 CRS を明示して使う」と理解するのが安全です。

### 隣接の定義：Queen と Rook

地図を描くだけなら「隣接」を考える必要はありませんが、次章以降で空間自己相関や空間回帰を行う際に「誰が誰の隣人か」を定義する必要があります。ここでは3つの代表的な隣接定義を紹介します。

- **Queen 型**: **辺または頂点**を共有していれば隣接とみなします。チェスのクイーンが八方向に動けるイメージです。つながりが多く、空間的影響を広く捉えます。
- **Rook 型**: **辺（境界線）を共有**している場合だけ隣接とみなします。チェスのルークが上下左右に動くイメージです。Queen より厳格です。
- **k 近傍（kNN）**: 各地域の重心から**距離が近い順に k 個**を隣接とします。島や飛地でも必ず隣接が定義でき、孤立ノードを回避できます。

#### 英語教育研究での選択指針

- **都道府県レベルの分析**: 行政的な隣接を仮説にするなら Queen は扱いやすい出発点です。ただし、辺/頂点の共有が研究上の接触メカニズムを表しているとは限らないため、Rook、kNN、距離ベースの重みとの感度分析を行います。
- **島嶼部を含む分析**: 沖縄や離島を含む場合は kNN（例: k = 4--6）を併用し、孤立ノードを回避します。
- **感度分析は必須**: 主要な結論が隣接定義の選択で変わらないかを確認します（次章 Section 4 で詳述します）。

以下のコードは参照用です。次章で実際に使用しますが、ここでは概念の理解のために掲載します。

```{r}
#| label: nb_demo
#| eval: false
# Queen（既定は queen=TRUE）
nb_queen <- spdep::poly2nb(pref_sf, queen = TRUE)
lw_queen <- spdep::nb2listw(nb_queen, style = 'W')

# Rook（辺共有のみ）
nb_rook  <- spdep::poly2nb(pref_sf, queen = FALSE)
lw_rook  <- spdep::nb2listw(nb_rook,  style = 'W')

# k 近傍（例: k=6）。代表点は投影座標上で作ると警告が出にくい

  sf::st_transform(3857) |>
  sf::st_point_on_surface()
knn      <- spdep::knearneigh(pref_points, k = 6)
nb_knn   <- spdep::knn2nb(knn)
lw_knn   <- spdep::nb2listw(nb_knn, style = 'W')
```

#### `nb` と `listw` の違い

上のコードには `nb` と `listw` の2つのオブジェクトが登場します。

- **`nb`（隣接リスト）**: 「都道府県Aの隣は B, C, D」という**接続情報**のみを持つオブジェクトです。重みはまだ付いていません。
- **`listw`（重み付き隣接）**: `nb` に**重み**を付加したものです。`style = 'W'`（行標準化）は、各地域の重みの合計が1になるように調整します。

空間分析の関数（`moran.test()`, `lagsarlm()` 等）は `listw` を入力として要求します。`nb` をそのまま渡すと「not a listw object」というエラーが出るので注意してください。

## 都道府県名の正規化（名寄せ）

形状データの都道府県名と、分析対象の指標データの都道府県名は、そのままでは一致しないことがあります。全角/半角、余分な空白、末尾の「都・道・府・県」の有無といった表記の揺れが原因です。以下の `norm_pref()` 関数は、この揺れを吸収して名寄せを可能にします。

```{r}
#| eval: true
#| label: norm_pref
# 正規化関数：全角/半角・空白・末尾の都/道/府/県の扱い
norm_pref <- function(x){
  x |>
    stringi::stri_trans_nfkc() |>
    stringr::str_replace_all("\\s+", "") |>
    stringr::str_replace("(東京都|北海道|京都府|大阪府)$", "") |>
    stringr::str_replace("県$", "")
}

# 形状側の正規化キー
jpn_key <- pref_sf |>
  st_drop_geometry() |>
  transmute(pref_name,
            pref_key = norm_pref(pref_name))
```

本章のRコードでは `|>` （ネイティブパイプ）を多用します。これは「左辺の結果を右辺の関数の第1引数に順番に渡す」記法です。`norm_pref()` の中身も、(1) NFKC正規化（全角/半角の統一）→ (2) 空白除去 → (3) 「東京都/北海道/京都府/大阪府」の除去 → (4) 末尾の「県」の除去、という処理を**上から下へ**読めば理解できます。名寄せで重要なのは、表記ゆれを吸収してから `anti_join()` で未対応の都道府県を洗い出すことです。実データに旧字体や略称がある場合は、`norm_pref()` に辞書置換を追加します。

## ダミーデータの作成（英語教育指標）

### 分析シナリオ

本章では、2018--2024年の7年間・47都道府県について、`eng_score`（英語学力複合スコア）、`teacher_toeic`（教員の平均TOEIC）、`eiken_rate`（英検準2級以上取得率）を追跡するシミュレーションデータを使います。ここでは単に「県ごとの平均が違う」だけではなく、**空間クラスタ**と**施策波及**が見えるように設計します。具体的には、首都圏と近畿圏に高値が集まりやすく、北日本にやや低い集積があり、2021年以降は首都圏の一部県で ALT 配置拡充施策が始まり、近隣県にも弱いスピルオーバーが起こるという設定です。こうした「地域差の地図化」と「政策文脈との接続」は、教育政策研究で学力や SES 勾配の地域差を読むときにも中心的な発想です [@reardon2019geography; @jang2019states]。

シミュレーションを使う理由は、地図・Moran's I・前後差分が**何を拾うはずか**を先に知っておくためです。真の空間パターンを埋め込んでおけば、あとで得られる結果が「コードの誤り」なのか「データの性質」なのかを切り分けやすくなります。

```{r}
#| eval: true
#| label: dummy_data
set.seed(2024)
years <- 2018:2024

pref_points <- pref_sf |>
  sf::st_transform(3857) |>
  sf::st_point_on_surface() |>
  sf::st_transform(4326)
pref_coords <- sf::st_coordinates(pref_points)
tokyo_hub <- sf::st_sfc(sf::st_point(c(139.6917, 35.6895)), crs = 4326)
osaka_hub <- sf::st_sfc(sf::st_point(c(135.5023, 34.6937)), crs = 4326)
sapporo_hub <- sf::st_sfc(sf::st_point(c(141.3545, 43.0618)), crs = 4326)

pref_features <- tibble::tibble(
  pref_name = pref_sf$pref_name,
  lon = pref_coords[, "X"],
  lat = pref_coords[, "Y"],
  dist_tokyo_km = as.numeric(units::set_units(sf::st_distance(pref_points, tokyo_hub), "km")),
  dist_osaka_km = as.numeric(units::set_units(sf::st_distance(pref_points, osaka_hub), "km")),
  dist_sapporo_km = as.numeric(units::set_units(sf::st_distance(pref_points, sapporo_hub), "km"))
) |>
  mutate(
    hot_kanto = exp(-(dist_tokyo_km / 260)^2),
    hot_kansai = exp(-(dist_osaka_km / 220)^2),
    cold_north = exp(-(dist_sapporo_km / 280)^2),
    treat_core = dist_tokyo_km <= 220,
    spillover = dist_tokyo_km > 220 & dist_tokyo_km <= 360
  )

pref_random <- tibble::tibble(
  pref_name = pref_features$pref_name,
  pref_intercept = rnorm(nrow(pref_features), 0, 1.8),
  toeic_random = rnorm(nrow(pref_features), 0, 18),
  eiken_random = rnorm(nrow(pref_features), 0, 0.02)
)

pref_panel <- tidyr::expand_grid(pref_name = pref_sf$pref_name, year = years) |>
  left_join(pref_features, by = "pref_name") |>
  left_join(pref_random, by = "pref_name") |>
  mutate(
    post = year >= 2021,
    policy_effect = if_else(post & treat_core, 3.0, 0) + if_else(post & spillover, 1.4, 0),
    common_trend = 0.55 * (year - min(years)),
    eng_score = round(
      55 + 7.5 * hot_kanto + 5.5 * hot_kansai - 4.5 * cold_north +
        pref_intercept + common_trend + policy_effect +
        rnorm(n(), 0, 1.8),
      1
    ),
    teacher_toeic = pmax(
      round(
        635 + 38 * hot_kanto + 22 * hot_kansai - 18 * cold_north +
          toeic_random + 4.5 * (year - min(years)) + 6 * policy_effect +
          rnorm(n(), 0, 16),
        0
      ),
      350
    ),
    eiken_rate = round(
      pmin(
        pmax(
          0.26 + 0.11 * hot_kanto + 0.07 * hot_kansai - 0.05 * cold_north +
            eiken_random + 0.012 * (year - min(years)) + 0.01 * policy_effect +
            rnorm(n(), 0, 0.02),
          0.05
        ),
        0.95
      ),
      3
    )
  ) |>
  dplyr::select(pref_name, year, eng_score, teacher_toeic, eiken_rate, treat_core, spillover)

pref_latest <- pref_panel |> dplyr::filter(year == max(year))
```

このシミュレーションでは、後の分析で少なくとも3つのパターンが見えるはずです。第1に、最新年の地図では首都圏と近畿圏に比較的高い値が集まり、北日本にやや低い集積が現れます。第2に、Moran's I は正の値になりやすく、LISA では高値集積と低値集積がそれぞれ見つかるはずです。第3に、2021年以降の前後差分地図では、施策中心県で大きな上昇、近隣県でやや小さい上昇が出るように作っています。

### 結合前のミスマッチ検出

形状データと指標データを結合する前に、**名寄せの成功を検証**します。`anti_join()` は「一方にあるが他方にない」レコードを抽出する関数で、ミスマッチの発見に威力を発揮します。

`anti_join()` は、Excel の照合で「対応が取れなかった行だけを抜き出す」操作に近いと考えると分かりやすいです。ここで未一致が残っていると、あとで地図に `NA` が大量に出るので、必ずこの段階で潰しておきます。

```{r}
#| eval: true

anti_data_vs_shape <- dplyr::anti_join(pref_panel_keyed, jpn_key, by = 'pref_key')
anti_shape_vs_data <- dplyr::anti_join(jpn_key, pref_panel_keyed, by = 'pref_key')
```

### 形状＋最新年指標の結合


`left_join(A, B, by = "key")` は、「Aの行をすべて残したまま、キーが一致するBの列を横に追加する」操作です。ここでは形状データ `pref_sf` を左側に置くことで、47都道府県のポリゴンを落とさずに保持できます。もし指標データ側に欠けがあれば `NA` が入るので、先ほどの `anti_join()` による事前確認が効いてきます。

表計算ソフトに慣れているなら、`left_join()` は `XLOOKUP` や `VLOOKUP` で列を追加する操作にかなり近いです。ただし地図では、左側に形状データを置くことが特に重要です。逆にすると「値はあるが形がない」状態になり、地図として描けなくなります。

### コロプレス図（塗り分け地図）

コロプレス図は、各地域を数値の大小に応じた色で塗り分ける地図です。英語教育研究では、全国の指標を俯瞰的に把握するための基本ツールとなります。

以下では、`classInt` パッケージの分位点区分（quantile）を用いて5段階に分類し、`ggplot2` で描画します。

**地図の読み方**: 濃い青が高スコア、薄い青が低スコアの地域です。ここでは、首都圏と近畿圏に濃い色がまとまり、北日本に薄い色がやや連なるかを見てください。もしそう見えるなら、それが後で Moran's I で検定する**正の空間自己相関**の視覚的な手がかりです。`geom_sf()` は `sf` オブジェクトの `geometry` 列を自動で読み取り、`aes(fill = ...)` に指定した変数で塗り分けます。

階級区分の選び方も地図解釈に直結します。今回の `quantile` は順位比較に向いており、47都道府県をおおむね均等な件数で5群に分けます。値の差そのものを見せたいときは `equal`、自然な谷で区切りたいときは `jenks` が候補になります。最初は `quantile` で全体像を見て、解釈が区分方法に依存しすぎていないかを後で確認する、という順で十分です。

最初に見る場所を1つに絞るなら、都道府県名より先に**色のまとまり**を見てください。つい「何県が一番高いか」に目が行きがちですが、地理空間分析では「高い県が並んでいるか」「低い県がかたまっているか」の方が次の分析に直結します。

一方で、コロプレス図は「何を塗っているか」によって解釈が大きく変わります。英語教育研究でよくある失敗は、受験者数や学校数のような**規模**をそのまま塗って、教育成果の地域差のように読んでしまうことです。地域間比較では、原則として平均、割合、標準化得点、人口・受験者数で割った率など、分母を明示できる指標を使います。また、系列地図では分類方法をそろえることが重要で、Brewer and Pickle は同じ主題の地図を並べるときに分類法が読み取りを左右することを示しています [@brewer2002]。本章の `quantile`、`equal`、`jenks` の比較は、見た目の違いを確認するだけでなく、「結論が分類方法に依存していないか」を点検するための作業です。

報告時には、図注に少なくとも「単位」「分母」「分類方法」「色尺度」を書いてください。たとえば「都道府県別の平均英語スコアを5分位で表示」「英検取得率を割合として表示」「全年で共通の連続色尺度を使用」のように明記します。これだけで、地図の読み過ぎと再現性の問題をかなり減らせます。

この図でわかること: 最新年にどの地域が相対的に高く、どの地域が低いかという点です。

この図だけではわからないこと: そのまとまりが統計的に有意かどうか、あるいは年を通じて安定しているかどうかという点です。

#### 階級区分を変えると地図はどう変わるか

同じデータでも、階級区分の方法を変えると見え方はかなり変わります。ここでは `quantile`、`equal`、`jenks` を並べて、どこが安定して高く見えるか、どこが区分方法によって印象が変わるかを確認します。

```{r}
#| eval: true
#| label: class_compare
#| fig-height: 4
#| fig-width: 10
make_class_map <- function(sf_obj, var, style) {
  brks <- classInt::classIntervals(var, n = 5, style = style)$brks
  sf_obj |>
    mutate(
      class = cut(var, breaks = unique(brks), include.lowest = TRUE),
      scheme = factor(style, levels = c("quantile", "equal", "jenks"))
    )
}

class_compare <- dplyr::bind_rows(
  make_class_map(pref_map, pref_map$eng_score, "quantile"),
  make_class_map(pref_map, pref_map$eng_score, "equal"),
  make_class_map(pref_map, pref_map$eng_score, "jenks")
)

ggplot(class_compare) +
  geom_sf(aes(fill = class), color = "gray40", size = .15) +
  scale_fill_brewer(palette = "Blues", na.value = "grey90", name = "Class") +
  facet_wrap(~ scheme, ncol = 3) +
  theme_geo() +
  labs(title = "Classification Comparison for the Same Data")
```

この比較で見たいのは、「どの県が常に高く見えるか」と「どの県が区分方法次第で印象が変わるか」です。`quantile` は順位比較、`equal` は数値差、`jenks` は自然な谷での区切りに向いています。入門では `quantile` を出発点にしつつ、この比較図で見え方が大きく変わらないかを確かめるだけでも十分です。

## 空間自己相関の初歩（Moran's I）

### なぜ空間自己相関を考える必要があるのか

コロプレス図を眺めて「高スコアの都道府県が集まっているように見える」と感じたとしても、それだけでは科学的な主張にはなりません。ランダムなデータでも、たまたまそう見えるパターンが出現することがあります。**Moran's I** は、観察された空間パターンが偶然で説明できるかどうかを統計的に検定する指標で、グローバルな空間自己相関を測る最も基本的な統計量です [@moran1950; @spdep]。

直感的には、Moran's I は**Pearson の相関係数 $r$ の空間版**です。

- Pearson の $r$: 2つの変数 $X$ と $Y$ の間の線形関連の強さを測る。
- Moran's $I$: ある地点の値と、その**隣接地域の加重平均値**との間の線形関連を測る。

$I > 0$ ならば、似た値が近接に集まる傾向（正の空間自己相関）。$I < 0$ ならば、異なる値が隣り合う傾向。$I \approx 0$ ならば、空間的にランダムな分布です。

ここでのポイントは、「高いか低いか」ではなく「**似たものどうしが近くにあるか**」を測っていることです。たとえば、全国平均が高くても低くても、地理的に入り混じっていれば Moran's I は大きくなりません。逆に、値そのものが中程度でも、似た県が近くに集まれば Moran's I は正になります。

英語教育研究で Moran's I を見る理由は2つあります。第1に、空間自己相関が強いと通常の OLS が仮定する「観測の独立」が崩れ、標準誤差や p 値の解釈が甘くなる可能性があります。第2に、もし高い英語力や高い教員 TOEIC が地理的に集まっているなら、その背景に地域経済、教員配置、学習資源、近隣自治体からの波及といった実質的メカニズムを考える必要があります。つまり Moran's I は、統計的診断であると同時に、次の研究課題を立てる入口でもあります [@bivand2013; @lovelace2019]。この発想は社会言語学でも同様で、地域変異の研究では「どこで似た発音や語法がまとまって現れるか」を地図化すること自体が理論的関心の一部です [@labov2006atlas; @grieve2016regional]。

### グローバル Moran's I の計算

```{r}
#| eval: true
#| label: moran_global
dat_moran <- pref_map |>
  dplyr::filter(!is.na(eng_score))

# 隣接（まず Queen）。孤立があれば k近傍で補完する
nb <- spdep::poly2nb(dat_moran, queen = TRUE)
deg <- spdep::card(nb)
augmented <- FALSE
if (any(deg == 0)) {
  rep_points <- dat_moran |>
    sf::st_transform(3857) |>
    sf::st_point_on_surface()
  k <- 1
  repeat {
    nb_knn <- spdep::knn2nb(spdep::knearneigh(rep_points, k = k))
    nb <- spdep::union.nb(nb, nb_knn)
    if (all(spdep::card(nb) > 0) || k >= 8) break
    k <- k + 1
  }
  augmented <- TRUE
}
lw <- spdep::nb2listw(nb, style = 'W', zero.policy = TRUE)
lw_moran <- if (augmented) spdep::listw2U(lw) else lw

# グローバル Moran（正の空間自己相関を検定）
moran_res <- spdep::moran.test(
  dat_moran$eng_score,
  lw_moran,
  zero.policy = TRUE,
  alternative = "greater"
)
moran_res

if (augmented) message('[注意] Queen に孤立があったため、k近傍で補完し、weights を対称化しました。')
```

この例では、シミュレーションに高値・低値の集積を埋め込んでいるので、`Moran I statistic` は正になりやすく、`p-value` も小さくなるはずです。`Expectation` はランダム配置ならどのくらいの値が期待されるかを示します。`spdep::moran.test()` の公式仕様では既定の対立仮説が `greater` なので、ここでも「正の空間自己相関があるか」を明示的に検定しています。また、kNN 補完で非対称な重みが混ざる可能性があるため、`listw2U()` で対称化してから解析的な Moran 検定に渡しています [@spdep]。

実務上は、「I が正で、p-value が十分小さいので、見た目のまとまりは偶然だけでは説明しにくい」と読めればまず十分です。反対に、p-value が大きいときは「地図に何となく模様は見えるが、少なくともこの重み行列の下では強い証拠とは言えない」と慎重に読む必要があります。

### ローカル Moran（LISA クラスタ図）

グローバル Moran's I は「全体として空間自己相関があるか」を示しますが、「**どの都道府県が**クラスタの一部か」は教えてくれません。ローカル Moran's I（LISA: Local Indicators of Spatial Association）は、各地域を以下の4タイプに分類するための局所統計量です [@anselin1995]。

- **High-High（HH）**: 自身も隣接も高い。「ホットスポット」。
- **Low-Low（LL）**: 自身も隣接も低い。「コールドスポット」。
- **High-Low（HL）**: 自身は高いが隣接は低い。空間的アウトライヤ。
- **Low-High（LH）**: 自身は低いが隣接は高い。空間的アウトライヤ。

```{r}
#| eval: true
#| label: lisa_map
# ローカル Moran（permutation ベース）
loc <- spdep::localmoran_perm(
  dat_moran$eng_score,
  lw_moran,
  nsim = 999,
  zero.policy = TRUE,
  alternative = "two.sided",
  iseed = 2024
)
dat_moran$Ii <- loc[, 'Ii']
p_perm <- loc[, "Pr(z != E(Ii)) Sim"]

z      <- as.numeric(scale(dat_moran$eng_score))
lag_z  <- spdep::lag.listw(lw_moran, z, zero.policy = TRUE)

cluster <- ifelse(p_perm >= 0.05, 'Not Sig',
           ifelse(z>0 & lag_z>0, 'High-High',
           ifelse(z<0 & lag_z<0, 'Low-Low',
           ifelse(z>0 & lag_z<0, 'High-Low', 'Low-High'))))

dat_moran$cluster <- factor(cluster, levels = c('High-High','Low-Low','High-Low','Low-High','Not Sig'))

ggplot(dat_moran) +
  geom_sf(aes(fill = cluster), color = 'white') +
  scale_fill_manual(
    values = c('High-High'='#d73027','Low-Low'='#4575b4','High-Low'='#fdae61','Low-High'='#74add1','Not Sig'='grey90'),
    drop = FALSE
  ) +
  theme_geo() +
  labs(title = "LISA Cluster Map (permutation p < .05)", fill = 'Cluster')
```

**読み方**: 赤い地域（HH）は英語力のホットスポット、青い地域（LL）はコールドスポットです。オレンジや水色は、周囲と逆方向にずれた空間的アウトライヤです。今回は `localmoran_perm()` による permutation ベースの p 値を使っており、解析的近似よりも解釈の入口として扱いやすい形にしています。ただし、LISA は都道府県ごとに複数の局所検定を並べるため、`p < .05` をそのまま「確定的証拠」と読むのではなく、**探索的なクラスタ候補**として扱うのが安全です [@spdep; @anselin1995]。教育政策研究でも社会言語学でも、局所クラスタ図は「さらに掘るべき場所」を見つけるための道具であり、単独で因果や境界の実在を確定するものではありません [@reardon2019geography; @grieve2016regional]。

最初に見る順番は、(1) 赤と青の大きな塊がどこにあるか、(2) 灰色が多いか少ないか、(3) オレンジや水色の外れた県がどこにあるか、の3つです。赤や青の塊は「まとまり」、灰色は「今回は局所統計量がはっきりしなかった場所」、オレンジや水色は「周囲とずれている場所」と読むと混乱しにくくなります。

この図でわかること: どの地域が局所的なホットスポット・コールドスポットかという点です。

この図だけではわからないこと: そのクラスタを生んだ原因や、境界が本当に固定的かどうかという点です。

```{r}
  geom_line(linewidth = 1, color = '#2c3e50') +
  geom_point(size = 2.5, color = '#2c3e50') +
  geom_hline(yintercept = 0, linetype = 'dashed', color = 'grey60') +
  theme_geo() +
  labs(title = 'Mean Year-on-Year Growth Rate (%)',
       x = 'Year', y = 'Growth Rate (%)')
```

この折れ線は、施策の因果効果を推定する図ではなく、都道府県を同じ重みで平均した伸び率がどの年に大きかったかを点検するための図です。2021 年以降に平均伸び率が少し上向くなら、後で描く前後差分地図のパターンと整合的かを見比べられます。一方で、全国的な景気や学習指導要領の変更でも同じ形は出るため、この図だけで施策評価はできません。

したがって、この図の役割は「施策が効いた」と結論づけることではなく、「2021 年以降に何か全体的な変化がありそうか」を先に眺めることです。地図の前に折れ線を見ることで、都道府県平均の変化と地域差の変化を混同しにくくなります。

この図でわかること: 都道府県平均として見た変化の山や谷の位置です。

この図だけではわからないこと: どの地域がその変化を主に担っているかという点です。

### 施策前後差分の地図

ここで見たいのは、単に「どこが上がったか」ではなく、「上昇が地理的にまとまっているか」です。もし施策中心県の周囲にも同方向の変化が見えるなら、空間的な波及を疑う出発点になります。

```{r}
#| eval: true
#| label: prepost_map
policy_year <- 2021
prepost <- pref_panel |>
  mutate(period = if_else(year < policy_year, 'pre', 'post')) |>
  group_by(pref_name, period) |>
  summarise(mean_score = mean(eng_score, na.rm = TRUE), .groups = 'drop') |>
  tidyr::pivot_wider(names_from = period, values_from = mean_score) |>
  mutate(diff_post_pre = post - pre)

map_diff <- pref_sf |>
  left_join(prepost, by = 'pref_name')

ggplot(map_diff) +
  geom_sf(aes(fill = diff_post_pre), color = 'white') +
  scale_fill_gradient2(low = '#4575b4', mid = 'white', high = '#d73027', midpoint = 0,
                       name = 'Diff (Post - Pre)') +
  theme_geo() +
  labs(title = paste0('Pre-Post Score Difference (Policy Year: ', policy_year, ')'))
```

**読み方**: 赤い地域は施策導入年以降にスコアが上昇、青い地域は低下した都道府県です。ここでは `year < 2021` を事前期間、`year >= 2021` を事後期間として、DID 側の `post` 定義と揃えています。このシミュレーションでは首都圏の施策中心県とその近隣県に正の差分が現れるように作っているので、その空間的広がりが視覚的に見えるかを確認してください。ただし、この地図だけでは施策効果は判定できません。全国トレンド（時間固定効果）や各都道府県固有の水準差（地域固定効果）を統制した比較が必要であり、次章では DID の枠組みでそこを扱います。因果推定の観点から見ると、前後差分はあくまで記述的な「変化量」であり、対照群や設計上の仮定なしに因果効果へ読み替えることはできません [@angrist2009]。教育政策研究でも、州や学区の文脈差が大きいため、見かけの地図パターンをそのまま政策効果と呼ばないことが重要です [@jang2019states]。

まず「赤がどこに集まっているか」を見れば十分です。その後で、「その赤い県はもともと高かったのか、もともと低かったのか」「近隣県にも同じ方向の変化があるか」を順に確かめると、単なる前後差と空間的波及の違いが見えやすくなります。

この図でわかること: 変化量がどこに集中しているかという点です。

この図だけではわからないこと: その変化が施策の因果効果か、全国トレンドや他の要因かという点です。

## インタラクティブ地図（leaflet）

ここまでの地図はすべて静的な画像でした。研究発表やデータ探索では、マウス操作で拡大・縮小やホバー情報表示ができるインタラクティブ地図が有用です。

ただし、`leaflet` は「厳密な比較」より「探索」に向いています。複数年を並べて色を見比べるのは静的図の方が得意で、`leaflet` は個別の県名や値をその場で確かめたいときに力を発揮します。

```{r}
#| label: leaflet_demo
#| eval: false
pacman::p_load(leaflet)
pal <- leaflet::colorBin('Blues', domain = pref_map$eng_score, bins = 5)
leaflet::leaflet(pref_map) |>
  leaflet::addProviderTiles(leaflet::providers$CartoDB.Positron) |>
  leaflet::addPolygons(fillColor = ~pal(eng_score), color = '#777', weight = 1,
              popup = ~paste0(pref_name, '<br>Score: ', eng_score)) |>
  leaflet::addLegend(pal = pal, values = ~eng_score, title = 'English Score')
```

`leaflet()` の公式ドキュメントでも、`data` に `sf` オブジェクトを直接渡し、`addProviderTiles()` で背景タイル、`addPolygons()` でポリゴン、`addLegend()` で凡例を重ねるのが基本パターンです [@leaflet]。`~eng_score` のようなフォーミュラ記法は、`ggplot2` の `aes(fill = eng_score)` に近い役割だと理解すると迷いにくくなります。なお、`leaflet` は既定で Web 地図用 CRS を使うので、公式 docs にある通り、CRS を自分で変えるのは意味が分かっている場合に限るのが安全です。このコードは `eval: false` なので、実際に試すときだけ `eval: true` に変更してください。

静的地図と `leaflet` の違いは、役割で分けると分かりやすいです。論文や本文では比較しやすい静的地図、探索や発表準備では県名や値をその場で確認しやすい `leaflet`、という使い分けが基本になります。

この図でわかること: 個々の県名や値を対話的に確認できることです。

この図だけではわからないこと: 年ごとの厳密な比較や、論文用の再現しやすい図示です。

## トラブルシューティング

### データ結合の問題

- **`left_join()` 後に値が全部 NA**: キー列の表記ゆれが原因です。`norm_pref()` で両側を正規化し、`anti_join()` でミスマッチを検出します。
- **結合後に行数が増えた**: キー列に重複があります。`count(pref_name, year)` で1行以上のレコードがないか確認します。
- **47都道府県に満たない**: 形状データまたは指標データで一部の都道府県が欠損しています。`n_distinct(pref_name)` で確認します。

### 形状データと CRS の問題

- **点とポリゴンの場所が合わない**: CRS が揃っていません。`st_crs()` で両方を確認し、`st_transform()` で統一します。
- **面積・距離がおかしい**: Web表示用 CRS をそのまま計測に使っている可能性があります。`sf` では geodesic 計算を使うか、研究地域に合った投影 CRS を明示してから平面距離・面積を計算します。
- **無効ジオメトリ（self-intersection）**: `st_is_valid()` で検出し、`st_make_valid()` で修復します。

### 可視化の問題

- **年次比較で色の印象がブレる**: `limits` を固定していません。`scale_fill_viridis_c(limits = global_limits)` で全パネル共通のスケールを指定します。
- **`geom_sf()` が重い/描画が遅い**: 高解像度の形状データを使用しています。試作段階では `st_simplify()` で簡略化するか、低解像度形状を使います。
- **日本語が文字化け（豆腐化）**: YAML の `mainfont` や R セッションのロケール（`Sys.setlocale()`）を見直します。Noto Serif JP / Noto Sans JP を推奨します。

### パネル整形の問題

- **`object 'pref_map' not found`**: チャンクの実行順序が原因です。Quarto で上から順に実行されていることを確認します。
- **`Inf` や `NaN` が混入**: 伸び率のゼロ割です。`if_else(prev == 0, NA, ...)` でガードするか、対数差分を使います。
- **欠損年が暗黙に無視されている**: `complete()` で明示的にパネルの格子を作成します。

### 解釈の問題

- **都道府県平均を個人差として読んでいる**: 都道府県単位の地図は地域平均の地図です。個人や学校の分布を直接示すものではありません。個人差を論じる場合は、個人・学校レベルのデータと階層構造を明示したモデルが必要です。
- **件数と率を混同している**: 受験者数や学校数のような件数は、人口規模や学校規模の地図になりやすいです。地域間比較では、平均、割合、人口当たり率、標準化得点など、分母を明示できる指標を優先します。
- **行政境界を自然な境界として読んでいる**: 都道府県境界は分析上の単位であり、学習資源、通学圏、教員移動、言語変化の境界と常に一致するわけではありません。境界の選び方を変えると結果が変わる可能性があります。

### 空間分析の問題

- **`regions with no neighbours`**: 島嶼部で孤立ノードが発生しています。kNN の k を引き上げるか、距離閾値で接続します。
- **`not a listw object`**: `nb` を直接渡しています。`nb2listw(nb, style = 'W')` で変換します。
- **`sfdep` と `spdep` の関数名の違いで混乱**: 本書では `spdep` を基本パッケージとして使用します。`sfdep::local_moran_perm` 等を使いたい場合は別途インストールが必要です。

### 提出前チェックリスト

- `anti_join()` の結果が 0 件か（名寄せ成功の確認）
- `st_crs()` が揃っているか（CRS の統一）
- ファセット比較でカラースケールが共通化されているか
- `st_is_valid()` で無効ジオメトリがないか
- パネルの行数 = 都道府県数 × 年数 ですか
- 地図化した値の単位・分母・分類方法を図注に書いていますか
- 都道府県平均から個人レベルの主張へ飛躍していませんか

本入門では、**形状の取得→名寄せ→結合→コロプレス→パネル整形→Moran's I の初歩**までを体験しました。データの読み込みから地図描画、パネルの品質管理まで、空間分析の「基礎工事」が完成しています。

次章（第15章: 応用編）では、この基礎の上に**分析的なツールキット**を構築します。

### 実データに置き換えるとき

本章のダミーデータを実データに差し替えるときは、列名・単位・集計レベル（都道府県か市区町村か）が一致しているかを最初に確認します。次に、指標定義や集計ルールの変更年がないかを注釈で管理します。名寄せでは `norm_pref()` に実データ固有の表記ゆれを追加し、都道府県名だけでなく市区町村コードや学校コードのような正式キーが使えるならそちらを優先します。実データでは `set.seed()` 自体は不要ですが、欠測補完やサンプリングを含む前処理をするなら再現性のために乱数種を明示しておくと安全です。
