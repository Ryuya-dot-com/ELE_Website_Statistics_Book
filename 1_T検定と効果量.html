4.1 はじめに

本章へようこそ。ここからは、英語教育研究で最も頻繁に登場する 2 群比較の手法、すなわち t 検定 (t-test) とその効果の実質的な大きさを示す 効果量 (effect size) を扱います。

t 検定は、2 つのグループの平均値を比べ、その差が 偶然のばらつきだけでは説明しにくいかどうかを調べる方法です。たとえば「Writing 群の平均点は Glossing 群より本当に高いのか、それとも今回たまたま高く見えただけなのか」を判断したいときに使います。

本章では、まず「連続量、または連続量に近い合計得点の平均差」をどう読むかに集中します。正解・不正解のような 2 値データや回数データ、より一般的な線形モデルについては、後続章で改めて取り上げます。

4.1.1 この章の到達目標

  • t 検定の前提条件を確認し、Welch の t 検定を中心に適切な手法を選べるようになる
  • 効果量(Cohen’s d, Hedges’ g, Glass’s Δ, 対応あり d)を計算し、p 値と分けて解釈できるようになる
  • サンプルサイズと検定力の関係を理解し、研究計画に必要な人数を見積もれるようになる
  • t 検定の結果を APA 第 7 版に沿って報告できるようになる

本章は本書の出発点であり、最も基本的な 2 群比較を扱います。まずは t 検定そのものを理解し、そのあとで回帰分析とのつながりも確認していきます。

4.2 データの作成

架空のデータセットを作成します。この研究では、50 人の参加者を 2 種類の語彙学習方法（注釈付き読解 [Glossing] vs. 文章作成 [Writing]）のいずれかにランダムに割り当てます。各群 25 人ずつで、各参加者は自分に割り当てられた方法だけで 15 語の目標語を学びます。学習後には、再生テスト (recall) と再認テスト (recognition) を学習直後 (Immediate) と 1 週間後 (Delayed) に受けます。

つまり、この章で中心的に扱う Treatment は 参加者間要因（between-subjects）です。したがって、Immediate の Recall における Glossing 群と Writing 群の比較は、独立 2 群の t 検定として説明できます。

4.2.1 主なパッケージの役割

  • tidyverse: データ生成、整形、可視化、本章全体のパイプラインの共通基盤。
  • effectsize: Cohen’s d、Hedges’ g などの効果量を一貫して算出する。
  • knitr: 計算結果と要約統計の表を整形する。
  • car / brunnermunzel: 前提確認やロバストな 2 群比較で補助的に使う。
  • compute.es / forcats / purrr / scales: 効果量の補助計算、因子処理、反復処理、図表整形に使う。

本書では R 4.1 以降のネイティブパイプ演算子 |> を使います。x |> f() は f(x) と同じ意味で、左側の結果を右側の関数へ順に渡します。

# パイプなし

シミュレーションデータは、最初に「誰がどの群か」を決め、そのあとで各参加者の項目反応を作る 2 段階で生成します。こうすると、between-subjects の設計がコード上でも見えやすくなります。

コード 
n_participants <- 50
n_items <- 15
treatments <- c("Glossing", "Writing")
tests <- c("Recall", "Recognition")
times <- c("Immediate", "Delayed")

participant_tbl <- tibble(
  Participant = factor(1:n_participants),
  Treatment = factor(

    levels = treatments
  )
)

participant_count_tbl <- participant_tbl |>
  count(Treatment)

この時点では、各参加者に Treatment が 1 つだけ割り当てられています。次に、その割り当てに基づいて各項目の得点を作ります。

コード 
dat <- tidyr::expand_grid(
  Participant = participant_tbl$Participant,
  Item = 1:n_items,
  Test = tests,
  Time = times
) |>
  left_join(participant_tbl, by = "Participant") |>
  mutate(
    base_prob = case_when(
      Treatment == "Glossing" & Test == "Recognition" ~ 0.50,
      Treatment == "Glossing" & Test == "Recall" ~ 0.20,
      Treatment == "Writing" & Test == "Recognition" ~ 0.90,
      TRUE ~ 0.50
    ),
    immediate_bonus = {
      set.seed(202402)
      if_else(
        Time == "Immediate",
        sample(0:1, size = n(), replace = TRUE),
        0L
      )
    },
    Score = {
      set.seed(202403)
      pmin(
        rbinom(n(), size = 1, prob = base_prob) + immediate_bonus,
        1L
      )
    }
  ) |>
  dplyr::select(-base_prob, -immediate_bonus)

Score 列はアイテムごとの正誤（1 = 正答、0 = 誤答）を表す 2 値データです。生データ全体は行数が多いので、まずは先頭 12 行だけを見て、各行が「1人 × 1項目 × 1種類のテスト × 1時点」を表していることを確認します。

t 検定や ANOVA では、目的変数は平均値と分散を意味のある形で扱える必要があります。そこで、参加者ごと・条件ごとにスコアを合計し、15 点満点の合計得点として、近似的に連続量のように扱える形へ変換します。

コード 
dat_summarized <- dat |>
  mutate(
    Participant = factor(Participant),
    Item = factor(Item),
    Treatment = factor(Treatment, levels = treatments),
    Test = factor(Test, levels = tests),
    Time = factor(Time, levels = times)
  ) |>
  group_by(Participant, Treatment, Test, Time) |>
  summarise(Score = sum(Score), .groups = "drop")

desc_stats <- dat_summarized |>
  group_by(Treatment, Test, Time) |>
  summarise(
    Mean = mean(Score),
    SD = sd(Score),
    N = n(),
    SE = SD / sqrt(N),
    CI_lower = Mean - qt(0.975, df = N - 1) * SE,
    CI_upper = Mean + qt(0.975, df = N - 1) * SE,
    .groups = "drop"
  ) |>
  mutate(across(where(is.numeric), \(x) round(x, 2)))

desc_stats |>
  knitr::kable()

記述統計を見ると、Writing の平均値が Glossing より高く、Immediate の方が Delayed より高い傾向が確認できます。

4.3 t 検定

R の統計関数では、Score ~ Treatment のようなフォーミュラ構文をよく使います。公式ドキュメントでは、左辺が目的変数、右辺が説明項を表すと整理されています (R Core Team, 2026a)。本章ではこれを「得点を学習条件で説明する」と読みます。

4.3.1 分析フロー

本章のメインルートは単純です。参加者ごとの合計得点を作り、Score ~ Treatment の形で Welch の t 検定を行い、平均値差の 95% 信頼区間と効果量を添えて報告します。

以下のフローチャートは、2 群比較における判断の流れを広めに示したものです。まず確認すべきなのは、目的変数の型と研究デザインです。Shapiro-Wilk 検定は便利な診断ですが、機械的な合否判定ではありません。分布の形、外れ値、サンプルサイズ、研究デザインを合わせて判断します。

4.3.2 t 検定を適用できるデータ

t 検定の目的変数は、平均値と分散を意味のある形で扱える連続量、または十分な段階数をもつ合計得点である必要があります。したがって、次のようなデータについては、t 検定をそのまま適用するのは控え、後続章で扱う適切な手法を選んでいただくのがよいでしょう。

  • 2 値データ（正答/誤答、合格/不合格）: ロジスティック回帰
  • 頻度データ（エラー回数、発話回数）: ポアソン回帰や負の二項回帰
  • 順序データ（5 段階尺度など）: 順序ロジスティック回帰

本章では、アイテムごとの 0/1 を参加者単位で合計し、15 点満点のスコアに変換したうえで、入門的な参加者レベル分析として t 検定を使います。15 点満点の得点は厳密には離散的で上限・下限もありますが、ここでは分布を確認しながら近似的にスケール得点として扱います。

分析単位の選択

同じデータでも、分析単位によって自然なモデルは変わります。参加者ごとの合計得点を比べるなら本章のような t 検定が使えます。正誤のまま参加者ごとの正答数/試行数を扱うなら二項モデル、項目レベルの正誤反応まで扱うならロジスティック混合効果モデルや項目応答理論が候補になります。

集約前のアイテムレベルデータを分析したい場合は、一般化線形混合モデルの方が自然です。

このデータ全体は、Treatment が参加者間要因、Time と Test が参加者内要因の混合デザインです。厳密には混合分散分析や混合効果モデルで一度に扱う方が自然ですが、本章では t 検定の考え方を学ぶことを優先し、Immediate の Recall だけを取り出して 2 群比較を行います。

コード 
dat_imm <- dat_summarized |>
  dplyr::filter(Time == "Immediate", Test == "Recall") |>
  mutate(Treatment = forcats::fct_relevel(Treatment, "Writing", "Glossing"))

dat_del <- dat_summarized |>
  dplyr::filter(Time == "Delayed", Test == "Recall") |>
  mutate(Treatment = forcats::fct_relevel(Treatment, "Writing", "Glossing"))

analysis_estimates <- dat_imm |>
  summarise(
    mean_writing = mean(Score[Treatment == "Writing"]),
    mean_glossing = mean(Score[Treatment == "Glossing"]),
    observed_diff = mean_writing - mean_glossing
  )

observed_diff <- analysis_estimates |>
  pull(observed_diff)

以降の検定では、Writing - Glossing が正になるように水準順を Writing, Glossing に揃えています。こうしておくと、t 値、平均差、効果量の符号が一貫して解釈しやすくなります。

4.3.4 統計的検定とは何か

統計的検定は、「見えている差が、偶然のばらつきだけでも起こりうる範囲なのか」を調べる手続きです。t 検定では、まず帰無仮説 \(H_0\) として「母平均に差はない」を置きます。そのうえで、もし本当に差がないなら、今回観測された平均値差がどれくらい珍しいかを確かめます。

直感的には、次の 3 ステップで考えると理解しやすくなります。

  1. まず「差はない」という出発点を置く。
  2. その世界で偶然だけによってどの程度の差が出るかを考える。
  3. 今回の差がその分布の端にあれば、「偶然だけでは説明しにくい」と判断する。

用語だけ先に整理すると、次の表のようになります。

以下では、Immediate の Recall データを使って、「もし群の違いが本当はなかったら」という世界を置換（ラベルの入れ替え）で再現します。置換による説明は、群ラベルを入れ替えてよいという交換可能性を仮定した概念的なデモです。赤い部分が「今回以上に極端な差」に相当します。

この図では、中央付近にある差は「偶然でもよく起こる差」、両端の赤い部分は「かなり珍しい差」です。今回のデータでは、観測された平均値差は帰無仮説のもとではあまり起こりにくく、その確率が p 値に対応します。ここでは有限回のランダム置換を使っているため、極端な置換が 0 回でも p 値を 0 とは報告せず、シミュレーション回数を踏まえて下限を示します。t 検定は、こうした発想を理論的な t 分布を使って効率よく計算する方法だと考えると理解しやすくなります。

ここで大事なのは、p 値は「帰無仮説が正しい確率」ではないという点です。p 値はあくまで、「差がないと仮定したときに今回以上の結果がどれくらい出るか」を表しています。

チュートリアル論文でも、p 値だけで結論を二分するのではなく、「差はどれくらい大きいか」「その推定にはどれくらい不確実性があるか」を同時に見ることが強く勧められています (Cumming, 2014; Lakens, 2013)。

4.3.5 前提条件の確認

実務上の確認ポイントは、次の 3 つです。

このうち 独立性 は特に重要です。独立性とは、「ある参加者の得点が、別の参加者の得点に引きずられていない」という前提です。たとえば同じペアで学習した、同じクラス内で強い相互作用がある、同じ教員のクラスが複数まとまっている、という状況では、観測値どうしが似やすくなります。

ここで重要なのは、独立性は Shapiro-Wilk 検定のように後から 1 つの関数で簡単に確認するものではなく、研究計画の段階で確保するものだという点です。独立性が怪しい場合は、t 検定よりもクラスや教員を考慮できる混合効果モデルの方が適切です。

また、群差が見つかったとしても、それだけで直ちに「介入の因果効果が証明された」と言えるわけではありません。ランダム割り当てが適切に行われていれば因果解釈に近づけますが、観察データや準実験デザインでは、事前差や交絡の可能性を考える必要があります。

4.3.6 検定の実施

t 統計量は、平均値差をその標準誤差で割った値です。言い換えると、「群間差が、ばらつきを踏まえてどれだけ大きいか」を表しています。p 値はその t 値と自由度から計算されますが、p 値そのものは効果の大きさを示しません。したがって、平均値差の信頼区間と効果量をセットで読むことが重要です。

ここで、最初に理解すべき数量は 3 つあります。

  • 平均値差: 実際に何点違うのか
  • 95%信頼区間: その差をどの程度の幅で見積もるべきか
  • p 値: 差が 0 だと仮定したときに、今回以上の結果がどれくらい珍しいか

この 3 つのうち、実際の教育研究で最も直感的なのは平均値差です。たとえば「平均で 2 点高い」はそのまま読み取れます。一方、効果量はその差を標準偏差で割った“比較しやすい尺度”、p 値はその差が偶然でも起こるかをみる尺度です。それぞれ役割が違います。

まず Welch の t 検定だけを確実に理解すれば十分 です。Student の t 検定やノンパラメトリック検定は、「前提やデータの性質が違うときにどうするか」を知るための発展事項として読むと整理しやすくなります。

4.3.7 95%信頼区間をどう読むか

95%信頼区間は、「もっともらしい差の範囲」を表す区間です。今回の例では、平均値差の95%信頼区間はおよそ 0.73 点から 2.87 点です。つまり、Writing 群の優位性は 0 点差付近ではなく、少なくとも 1 点程度はありそうだ、と読みます。

ただし、95%信頼区間を「真の値が95%の確率でこの中にある」とそのまま言い換えるのは、頻度主義統計の厳密な言い方ではありません。正確には、「同じ手続きを何度も繰り返したとき、そのたびに作られる区間の 95% が真の値を含む」という意味です。それでも実務上は、「どれくらいの差がもっともらしいかを見る幅」と理解しておけば十分役に立ちます。

特に意識するとよいのは次の 2 点です。

  • 区間が狭いほど 推定は精密
  • 区間が広いほど 推定には不確実性が大きい

今回の章では p 値だけでなく、この信頼区間を必ず併記する方針をとっています。これは Cumming が強調する “new statistics” の考え方とも一致します (Cumming, 2014)。

この「95%」という言い方を直感的に理解するには、同じ条件で研究を何度も繰り返す場面を思い浮かべると役立ちます。下の図では、同じ母集団から 80 回研究を繰り返し、そのたびに平均値差の 95% 信頼区間を作っています。

コード 
true_p_glossing <- 0.54
true_p_writing <- 0.68
true_diff_ci <- 15 * (true_p_writing - true_p_glossing)
n_ci_demo <- 25
n_rep_ci <- 80
set.seed(202405)

ci_demo <- purrr::map_dfr(1:n_rep_ci, \(i) {
  writing_scores <- rbinom(n_ci_demo, size = 15, prob = true_p_writing)
  glossing_scores <- rbinom(n_ci_demo, size = 15, prob = true_p_glossing)
  ci_result <- t.test(writing_scores, glossing_scores)

  tibble(
    Study = i,
    Estimate = mean(writing_scores) - mean(glossing_scores),
    CI_low = ci_result$conf.int[1],
    CI_high = ci_result$conf.int[2],
    Covers = ci_result$conf.int[1] <= true_diff_ci &
      ci_result$conf.int[2] >= true_diff_ci
  )
}) |>
  mutate(Study = factor(Study, levels = rev(unique(Study))))

ggplot(ci_demo, aes(x = Estimate, y = Study, color = Covers)) +
  geom_vline(xintercept = true_diff_ci, linetype = "dashed", color = "grey40") +
  geom_segment(
    aes(x = CI_low, xend = CI_high, yend = Study),
    linewidth = 0.8
  ) +
  geom_point(size = 1.8) +
  scale_color_manual(
    values = c(`TRUE` = "steelblue4", `FALSE` = "firebrick"),
    labels = c(`TRUE` = "Covers the true difference", `FALSE` = "Does not cover the true difference")
  ) +
  labs(
    x = "Mean difference",

この図で青い区間は真の差を含んでおり、赤い区間は含んでいません。95% 信頼区間とは、「今作った 1 本の区間に 95% の確率で真の値が入る」という意味ではなく、同じ手続きを何度も繰り返したとき、作られる区間の約 95% が真の値を含むという長期的な性質を表しています。この例でも、80 本中 77 本の区間が真の差を含んでいます。

サンプルサイズが増えると CI はどう変わるか

信頼区間の幅は、ばらつきだけでなくサンプルサイズにも強く依存します。簡単のため、各群のばらつきが同程度である状況を仮定すると、各群の人数が増えるほど平均値差の標準誤差が小さくなり、信頼区間は狭くなります。

4.4 t 検定と回帰分析のつながり

ここまで t 検定を 2 群比較として見てきました。ここで一度、t 検定が単回帰分析とどうつながるかを確認しておきます。

回帰分析は、一般に

\[ Y = b_0 + b_1 X + \varepsilon \]

という形で表されます。lm() もこの形のモデルを当てはめる関数です (R Core Team, 2026b)。

  • \(X\) が連続変数なら、回帰直線は傾きをもつ通常の単回帰になります。
  • \(X\) が 0/1 の 2 値変数なら、\(b_0\) は 0 群の平均、\(b_1\) は 1 群と 0 群の平均値差になります。

つまり、2 群の平均値差を調べる t 検定は、「説明変数が 2 水準だけの回帰分析」として書き直すことができます。

コード

2 水準の要因に対する ANOVA の \(F\) 検定は、この Student の t 検定を二乗したものとして理解できます。つまり、2 群比較で見ている平均値差の考え方は、第2章で扱う ANOVA やカテゴリカル変数のコーディングへそのままつながります。

4.5 効果量

p 値は「差があるか」を問う指標であり、「差がどれくらい大きいか」を直接は教えてくれません。t 検定の結果を報告するときは、効果量を合わせて示すことで、実質的な意味を読み取りやすくなります (Lakens, 2013)。近年の応用言語学では、p 値と効果量をセットで報告することが標準的な作法となりつつあります。

4.5.1 標準化効果量の種類

  • Cohen’s d: 平均値差をプールした標準偏差で割った値。最も基本的な標準化平均差です (Cohen, 1988)。
  • Hedges’ g: Cohen’s d に小標本補正係数 \(J(\nu) = \Gamma(\nu/2) / [\sqrt{\nu/2}\,\Gamma((\nu-1)/2)]\) (近似式 \(J(\nu) \approx 1 - 3/(4\nu - 1)\)) を掛けて、自由度 \(\nu\) が小さいときの過大推定を抑えたもの (Hedges, 1981)。サンプルサイズが小さい研究やメタ分析でよく使われます。
  • Glass’s Δ: 対照群の標準偏差だけで標準化する指標 (Glass, 1976)。介入によって実験群の分散が変わる可能性があるときに、対照群の散らばりを基準として固定したい場合に有用です。

代表的な目安として、Cohen は \(d = 0.2, 0.5, 0.8\) を small, medium, large と整理しました (Cohen, 1988)。ただし、Cohen 自身が「分野固有の根拠が得られないときに限って参照すべき便宜的な定義 (operational definitions)」と注意していた点は強調しておく必要があります。文脈に即した解釈を置き換えるものではありません (Cohen, 1988; Lakens, 2013)。本章の検定力図では参考値として \(d = 1.2\) も示しますが、Cohen の基本的な目安は次の 3 段階です。

第二言語習得研究に固有の目安

応用言語学・SLA の文脈では、Cohen の目安は実態より厳しすぎるという指摘があります。Plonsky と Oswald は 346 本の L2 研究を集計し、研究デザイン別の経験的な参照値を提案しました (Plonsky & Oswald, 2014)。

群内 d (前後比較などの対応あり設計) が群間 d より大きく見積もられているのは、参加者内のばらつきが分母に入らない分、同じ介入でも値が大きく出やすいからです (Plonsky & Oswald, 2014)。SLA 系の論文では、Cohen の伝統的な目安より Plonsky & Oswald の参照値の方が研究実態に即していると理解しておくと、報告時の解釈ぶれが減ります。

ただし、これらも分野平均を整理した「典型値」であって、固定的な合否基準ではありません。たとえば教育介入のコストや測定の精度を勘案すれば、\(d = 0.30\) でも実務的に重要な差として扱う場面はあります。次節で見るように、近年は「研究計画段階で『どの程度の差なら実務的に意味があるか』を事前に決める」という発想 (smallest effect size of interest, SESOI) が推奨されています (Lakens, 2022)。

どの効果量を主に報告するかは、研究目的と分散の扱いによって変わります。

4.5.2 効果量の計算

effectsize パッケージは、Cohen’s d, Hedges’ g, Glass’s Δ を同じ記法で計算でき、95% 信頼区間も併せて出力します (Ben-Shachar et al., 2024)。ここでは reference = "Glossing" を明示し、正の値が「Writing 有利」を意味するように符号を固定します。Cohen’s d はプールした標準偏差を分母にする記述的な標準化平均差なので、Welch の t 検定を主報告にする場合でも、平均値差とその CI を主に読み、標準化効果量は分母を明記して補助的に解釈します。

4.5.5 効果量の変換

Cohen’s d から相関係数 \(r\) への変換は、次の式で表せます。

\[ r = \frac{d}{\sqrt{d^2 + a}} \]

ここで \(a = \frac{(n_1 + n_2)^2}{n_1 n_2}\) です。メタ分析のように研究間で指標をそろえたいときには、こうした変換式が役立ちます。研究統合では Hedges’ g を報告しておくと再利用しやすくなります。

4.6 「有意差がない」と「等価である」は違う

「p > .05 だったので差はなかった」という記述は、研究者が無意識に書いてしまいがちですが、統計的には正確ではありません。

通常の有意差検定では、帰無仮説は「差が 0」です。したがって、p > .05 だったときに言えるのは、「帰無仮説を棄却できなかった」 ということだけです。ここで「帰無仮説を採択した」「差がないことが証明された」とまでは言えません。

もし本当に主張したいことが「条件間に意味のある差はない」であれば、通常の t 検定ではなく 等価性検定（equivalence testing）を使う必要があります (Lakens et al., 2018)。

等価性検定では、発想が逆になります。

  • 通常の有意差検定: 「差は 0」を出発点にして、それを棄却できるかを調べる。
  • 等価性検定: 「差は無視できるほど小さくはない」を出発点にして、それを棄却できるかを調べる。

実務では、まず「どの程度までの差なら実質的に同じとみなすか」を 等価性境界（equivalence bounds, SESOI: smallest effect size of interest）として事前に決めます。たとえば 15 点満点の再生テストなら、「平均差の絶対値が 1 点未満なら実務上は同じとみなす」という境界を置くことが考えられます。

TOST（two one-sided tests）では、\(\alpha = .05\) の等価性検定において、90% 信頼区間がこの等価性境界の内側に完全に収まれば、「実質的に等価」と判断できます。通常の両側 5% 有意差検定では 95% 信頼区間が 0 を含むかどうかを見るため、ここで使う 90% 信頼区間とは役割が異なります。次の図は、その考え方を概念的に示したものです。

コード

    c("Clear positive difference", "Inconclusive", "Practically equivalent"),

この図の読み方は次のとおりです。

  • 差が明確に正方向: この概念図では信頼区間が 0 から離れており、等価性境界の外側にあります。通常の両側 5% 有意差検定では、別途 95% 信頼区間または p 値で判断します。
  • 結論保留: 0 をまたいでいて、なおかつ等価性境界にも収まっていない。差があるとも、十分小さいとも言えない。
  • 実質的に等価: 90% 信頼区間が等価性境界の内側に完全に収まっている。差があっても、事前に決めた基準より小さいといえる。

要するに、通常の t 検定で p > .05 だったからといって「差がない」とは言えません。その主張をしたいなら、事前に「どれくらい小さければ同じとみなすか」を定め、等価性検定を別途行う必要があります。

4.7 チュートリアル論文からの実務的なまとめ

この章で採用している方針は、近年のチュートリアル論文の勧めと整合するように組んでいます。

  1. p 値だけで終わらせず、効果量と信頼区間を必ず見る。Lakens の実践的レビューや Cumming の “new statistics” は、この点を強く勧めています (Cumming, 2014; Lakens, 2013)。
  2. 独立 2 群比較では Welch を標準とする。Student の t 検定は等分散が強く妥当なときに限れば使えますが、実務上は Welch を主に使う方が安全です (Delacre et al., 2017)。
  3. p > .05 を「差がない」と読み替えない。その主張には、等価性境界を事前に定めた等価性検定が必要です (Lakens et al., 2018)。
  4. 検定力は事後より事前に使う。観測後の “observed power” より、計画段階での a priori power analysis の方が研究設計に役立ちます (Hoenig & Heisey, 2001)。

この 4 点を理解しておくと、t 検定を単なる「p 値を出す手順」としてではなく、推定・不確実性・実質的重要性を含めた分析の入口として理解しやすくなります。

4.8 サンプルサイズと検定力分析

研究計画の段階では、期待する効果量に対して 何人必要かを見積もっておくことが、再現可能な研究のための第一歩になります。Lakens のサンプルサイズ正当化論文 (Lakens, 2022) は、伝統的な検定力分析にとどまらず、実質的に意味のある最小効果量 (smallest effect size of interest, SESOI) を事前に決めて、その値に対して計画する発想を体系的に整理しています。L2 研究では、Plonsky & Oswald の参照値 (Plonsky & Oswald, 2014) や先行メタ分析 (例: Norris & Ortega (2000)) の効果量分布を起点に SESOI を設定する方法が現実的です。

R の公式ドキュメントにある power.t.test() は、平均値差 delta と標準偏差 sd を使って検定力計算を行います (R Core Team, 2026c)。ここでは標準化効果量 \(d\) を使いたいので、sd = 1 と置き、delta = d として扱います。type = "two.sample" のとき、n は総サンプルサイズではなく 各群の人数である点にご注意ください。

先ほど見たように、サンプルサイズが大きいほど信頼区間は狭くなります。検定力分析は、その同じ事実を「差を検出できる確率」という観点から見直したものです。

コード 
power_from_d <- function(d, n = NULL, power = NULL, sig.level = 0.05,
                         type = "two.sample", alternative = "two.sided") {
  stats::power.t.test(
    n = n,
    delta = d,
    sd = 1,
    sig.level = sig.level,
    power = power,
    type = type,
    alternative = alternative
  )
}

事前の計画には有用ですが、観測された効果量をそのまま代入した「事後検定力」は新しい情報をほとんど増やしません (Hoenig & Heisey, 2001)。そのため、ここでは a priori の検定力分析に絞ります。

ここも一文で言うと、研究を始める前に「何人いれば差を見つけやすいか」を決めるのが検定力分析です。

4.8.2 発展: シミュレーションで検定力を見積もる

power.t.test() は、標準化効果量を指定して素早く必要人数を見積もれる便利な関数です。一方、実際のテスト得点は 15 点満点のように上限と下限があり、必ずしも完全な正規分布にはなりません。そこで経験者向けには、データを発生させる → t 検定を行う → 有意になった割合を数える というシミュレーションも有用です。

考え方は単純です。たとえば「Glossing 群の正答確率が .62、Writing 群の正答確率が .72 なら、15 点満点では平均差が約 1.5 点になる」と仮定します。その仮定のもとで研究を何度も仮想的に繰り返し、どれくらいの割合で p < .05 になるかを見ます。

コード 
simulate_ttest_once <- function(n_per_group, p_glossing, p_writing,
                                n_items = 15, alpha = 0.05) {
  glossing_scores <- rbinom(n_per_group, size = n_items, prob = p_glossing)
  writing_scores <- rbinom(n_per_group, size = n_items, prob = p_writing)
  test_result <- t.test(writing_scores, glossing_scores)

  tibble(
    p_value = test_result$p.value,
    significant = test_result$p.value < alpha,
    mean_diff = mean(writing_scores) - mean(glossing_scores),
    ci_width = diff(test_result$conf.int)
  )
}

simulate_ttest_behavior <- function(n_per_group, p_glossing, p_writing,
                                    n_items = 15, nsim = 600,
                                    alpha = 0.05) {
  purrr::map_dfr(
    seq_len(nsim),
    \(i) simulate_ttest_once(
      n_per_group = n_per_group,
      p_glossing = p_glossing,
      p_writing = p_writing,
      n_items = n_items,
      alpha = alpha
    )
  ) |>
    summarise(
      rejection_rate = mean(significant),
      average_mean_diff = mean(mean_diff),
      average_ci_width = mean(ci_width),
      .groups = "drop"
    )
}

4.10 トラブルシューティング

t 検定を実際に使い始めると遭遇しやすい 5 つの状況について、原因と対処法を整理します。該当する項目だけ参照する形でも構いません。

4.10.1 p 値は有意でも効果量が小さいときは?

「p < .001 で有意な結果が出たのに、Cohen’s d を計算したら 0.1 程度しかなく、解釈に困ってしまった」 — このような状況は、特にサンプルサイズが大きい研究で起こりやすいパターンです。

原因: サンプルサイズが大きいほど、ごくわずかな差でも p 値は小さくなります。これは検定の数学的性質であり、必ずしも実質的に意味のある差を反映しているわけではありません。

対処: p 値だけで結論を書かず、効果量とその信頼区間を必ず併記するのが安全です。「統計的に有意である」と「実質的に意味のある差である」は別物として扱う習慣をつけてください。

4.10.2 「p > .05 だから差がない」と書きたくなったときは?

論文の Discussion で「群間に有意差は見られなかった (p > .05) ため、両条件は同等の効果を持つ」と書きたくなる場面があるかもしれません。しかしここは慎重に扱う必要があります。

原因: p > .05 は「差がないことの証明」ではなく、「差があるとは言い切れなかった」という意味でしかありません。検定力不足で差が見えなかった可能性も含まれます。

対処: 本当に「条件間に意味のある差はない」と主張したいのであれば、通常の t 検定ではなく、本章の「「有意差がない」と「等価である」は違う」節で扱った 等価性検定(等価性境界を事前に決めて行う検定)を採用するのがよいでしょう。

4.10.3 対応ありと対応なしを取り違えてしまったら?

同一参加者の Pre/Post を比較しているのに paired = TRUE を付け忘れる、あるいは逆に独立 2 群なのに対応ありで処理してしまう — これも初期にやりがちなミスです。

原因: 対応の有無を間違えると、標準誤差の計算が崩れ、p 値も信頼区間も信用できなくなります。

対処: データを目の前にして、まず 「同じ参加者 ID が両群に登場するか?」 を確認してみてください。登場するなら対応あり (t.test(..., paired = TRUE) および cohens_d(..., paired = TRUE))、登場しないなら対応なしが原則です。

4.10.4 効果量や t 値の符号が逆になってしまうときは?

cohens_d() の出力符号が、自分の予想と逆になっていて戸惑った、という経験はありませんか? これは群の並び順が暗黙のうちに決まってしまうために起こります。

原因: R は要因の水準順序(アルファベット順がデフォルト)で「どちらを基準にするか」を勝手に決めます。そのため、どちらが正でどちらが負か、コードを見ただけでは分からなくなりがちです。

対処: 本章では Writing - Glossing が正になるように forcats::fct_relevel() で水準順を明示し、cohens_d() でも reference = "Glossing" を指定しました。「どちらを基準に差を取ったか」を必ずコードと報告文の両方に明記してください。

4.10.5 同じデータに何度も t 検定をかけたくなったら?

「3 群を 2 群ずつ全ペアで比較すれば 3 回の t 検定で済む」と考えてしまうのは自然な発想ですが、ここには 多重比較の罠が潜んでいます。

原因: 複数回の検定を同じ有意水準 (α = .05) で行うと、少なくとも 1 つで偽陽性が出る確率は急速に上がります(α = .05 で 3 回なら約 14%)。

対処: 比較が複数あるなら、ANOVA や混合効果モデルで一度に扱う方が原理的に自然です(第 2・6 章を参照ください)。やむを得ず複数の t 検定を行う場合は、Holm 法や Bonferroni 補正などの多重比較調整を検討してください。p.adjust() 関数で簡単に補正できます。

## はじめに

本章へようこそ。ここからは、英語教育研究で最も頻繁に登場する **2 群比較**の手法、すなわち **t 検定 (t-test)** とその効果の実質的な大きさを示す **効果量 (effect size)** を扱います。

t 検定は、2 つのグループの平均値を比べ、その差が **偶然のばらつきだけでは説明しにくいかどうか**を調べる方法です。たとえば「Writing 群の平均点は Glossing 群より本当に高いのか、それとも今回たまたま高く見えただけなのか」を判断したいときに使います。

本章では、まず「**連続量、または連続量に近い合計得点の平均差**」をどう読むかに集中します。正解・不正解のような 2 値データや回数データ、より一般的な線形モデルについては、後続章で改めて取り上げます。

### この章の到達目標

- t 検定の前提条件を確認し、Welch の t 検定を中心に適切な手法を選べるようになる
- 効果量(Cohen's *d*, Hedges' *g*, Glass's Δ, 対応あり *d*)を計算し、p 値と分けて解釈できるようになる
- サンプルサイズと検定力の関係を理解し、研究計画に必要な人数を見積もれるようになる
- t 検定の結果を APA 第 7 版に沿って報告できるようになる

本章は本書の出発点であり、最も基本的な 2 群比較を扱います。まずは t 検定そのものを理解し、そのあとで回帰分析とのつながりも確認していきます。

## データの作成

架空のデータセットを作成します。この研究では、50 人の参加者を 2 種類の語彙学習方法（注釈付き読解 [Glossing] vs. 文章作成 [Writing]）のいずれかにランダムに割り当てます。各群 25 人ずつで、各参加者は自分に割り当てられた方法だけで 15 語の目標語を学びます。学習後には、再生テスト (recall) と再認テスト (recognition) を学習直後 (Immediate) と 1 週間後 (Delayed) に受けます。

つまり、この章で中心的に扱う Treatment は **参加者間要因**（between-subjects）です。したがって、Immediate の Recall における Glossing 群と Writing 群の比較は、独立 2 群の t 検定として説明できます。

## t 検定

R の統計関数では、`Score ~ Treatment` のようなフォーミュラ構文をよく使います。公式ドキュメントでは、左辺が目的変数、右辺が説明項を表すと整理されています [@rstatsformula]。本章ではこれを「**得点を学習条件で説明する**」と読みます。

### t 検定を適用できるデータ

t 検定の目的変数は、平均値と分散を意味のある形で扱える連続量、または十分な段階数をもつ合計得点である必要があります。したがって、次のようなデータについては、t 検定をそのまま適用するのは控え、後続章で扱う適切な手法を選んでいただくのがよいでしょう。

- 2 値データ（正答/誤答、合格/不合格）: ロジスティック回帰
- 頻度データ（エラー回数、発話回数）: ポアソン回帰や負の二項回帰
- 順序データ（5 段階尺度など）: 順序ロジスティック回帰

本章では、アイテムごとの 0/1 を参加者単位で合計し、15 点満点のスコアに変換したうえで、入門的な参加者レベル分析として t 検定を使います。15 点満点の得点は厳密には離散的で上限・下限もありますが、ここでは分布を確認しながら近似的にスケール得点として扱います。

::: {.callout-note}
## 分析単位の選択

同じデータでも、分析単位によって自然なモデルは変わります。参加者ごとの合計得点を比べるなら本章のような t 検定が使えます。正誤のまま参加者ごとの正答数/試行数を扱うなら二項モデル、項目レベルの正誤反応まで扱うならロジスティック混合効果モデルや項目応答理論が候補になります。
:::

集約前のアイテムレベルデータを分析したい場合は、一般化線形混合モデルの方が自然です。

このデータ全体は、Treatment が参加者間要因、Time と Test が参加者内要因の混合デザインです。厳密には混合分散分析や混合効果モデルで一度に扱う方が自然ですが、本章では t 検定の考え方を学ぶことを優先し、Immediate の Recall だけを取り出して 2 群比較を行います。

### 統計的検定とは何か

統計的検定は、「見えている差が、偶然のばらつきだけでも起こりうる範囲なのか」を調べる手続きです。t 検定では、まず帰無仮説 $H_0$ として「母平均に差はない」を置きます。そのうえで、もし本当に差がないなら、今回観測された平均値差がどれくらい珍しいかを確かめます。

直感的には、次の 3 ステップで考えると理解しやすくなります。

1. まず「差はない」という出発点を置く。
2. その世界で偶然だけによってどの程度の差が出るかを考える。
3. 今回の差がその分布の端にあれば、「偶然だけでは説明しにくい」と判断する。

用語だけ先に整理すると、次の表のようになります。

| 用語 | この章での意味 |
|---|---|
| 帰無仮説 $H_0$ | Glossing 群と Writing 群の母平均に差はない |
| 対立仮説 $H_1$ | 2群の母平均に差がある |
| 検定統計量 | 今回の差が標準誤差の何倍かを表す値 |
| p 値 | $H_0$ のもとで今回の検定統計量と同じか、それ以上に極端な値が得られる確率 |
| 効果量 | 差の大きさそのもの |

: 統計的検定の基本用語 {#tbl-hypothesis-terms}

以下では、Immediate の Recall データを使って、「もし群の違いが本当はなかったら」という世界を置換（ラベルの入れ替え）で再現します。置換による説明は、群ラベルを入れ替えてよいという交換可能性を仮定した概念的なデモです。赤い部分が「今回以上に極端な差」に相当します。

```{r}
#| eval: true
#| label: fig-permutation-null
#| fig-width: 7
#| fig-height: 4.5
#| fig-cap: "帰無仮説のもとでの平均値差の置換分布"
#| fig-alt: "群ラベルを3000回置換して得た平均値差のヒストグラム。観測された平均値差以上に極端な両端部分が赤く塗られている。"

n_perm <- 3000
set.seed(202404)

perm_diffs <- replicate(n_perm, {
  permuted_treatment <- sample(dat_imm$Treatment)
  mean(dat_imm$Score[permuted_treatment == "Writing"]) -
    mean(dat_imm$Score[permuted_treatment == "Glossing"])

perm_extreme <- abs(perm_diffs) >= abs(observed_diff)
perm_p <- (sum(perm_extreme) + 1) / (n_perm + 1)
perm_p_label <- if (sum(perm_extreme) == 0) {
  paste0("< ", format.pval(1 / (n_perm + 1), digits = 3))
} else {
  format.pval(perm_p, digits = 3)
}

perm_tbl <- tibble(
  Difference = perm_diffs,
  Extreme = perm_extreme
)

ggplot(perm_tbl, aes(x = Difference, fill = Extreme)) +
  geom_histogram(bins = 50, color = "white") +
  geom_vline(
    xintercept = c(-abs(observed_diff), abs(observed_diff)),
    color = "firebrick",
    linetype = "dashed",
    linewidth = 0.9
  ) +
  scale_fill_manual(
    values = c("FALSE" = "grey80", "TRUE" = "#F4A6A6"),
    guide = "none"
  ) +
  labs(
    x = "Mean difference under the null hypothesis",
    y = "Count",
    title = "Mean differences under the null hypothesis",

```

この図では、中央付近にある差は「偶然でもよく起こる差」、両端の赤い部分は「かなり珍しい差」です。今回のデータでは、観測された平均値差は帰無仮説のもとではあまり起こりにくく、その確率が p 値に対応します。ここでは有限回のランダム置換を使っているため、極端な置換が 0 回でも p 値を 0 とは報告せず、シミュレーション回数を踏まえて下限を示します。t 検定は、こうした発想を理論的な t 分布を使って効率よく計算する方法だと考えると理解しやすくなります。

ここで大事なのは、**p 値は「帰無仮説が正しい確率」ではない**という点です。p 値はあくまで、「差がないと仮定したときに今回以上の結果がどれくらい出るか」を表しています。

チュートリアル論文でも、p 値だけで結論を二分するのではなく、「差はどれくらい大きいか」「その推定にはどれくらい不確実性があるか」を同時に見ることが強く勧められています [@lakens2013; @cumming2014]。

### 前提条件の確認

実務上の確認ポイントは、次の 3 つです。

| 前提 | 主な確認方法 | 実務上の判断 |
|---|---|---|
| 正規性 | `shapiro.test()`, QQ プロット, ヒストグラム | 大標本では図も重視する |
| 等分散性 | 群ごとの散らばり, `leveneTest()` | 主報告は Welch を使う |
| 独立性 | 研究デザイン | 統計関数だけでは補えない |

: t 検定で確認する主な前提 {#tbl-ttest-assumptions}

このうち **独立性** は特に重要です。独立性とは、「ある参加者の得点が、別の参加者の得点に引きずられていない」という前提です。たとえば同じペアで学習した、同じクラス内で強い相互作用がある、同じ教員のクラスが複数まとまっている、という状況では、観測値どうしが似やすくなります。

ここで重要なのは、独立性は Shapiro-Wilk 検定のように後から 1 つの関数で簡単に確認するものではなく、**研究計画の段階で確保するもの**だという点です。独立性が怪しい場合は、t 検定よりもクラスや教員を考慮できる混合効果モデルの方が適切です。

また、群差が見つかったとしても、それだけで直ちに「介入の因果効果が証明された」と言えるわけではありません。ランダム割り当てが適切に行われていれば因果解釈に近づけますが、観察データや準実験デザインでは、事前差や交絡の可能性を考える必要があります。

#### Shapiro-Wilk 検定

`shapiro.test()` の帰無仮説は「データは正規分布に従う」です [@rstatsshapiro]。したがって、p 値が大きいときは「正規性からの有意な逸脱は検出されない」と解釈します。

```{r}
#| eval: true
#| label: tbl-shapiro
#| tbl-cap: "Immediate recall に対する Shapiro-Wilk 検定"

  Treatment = c("Writing", "Glossing"),
  W = c(
    shapiro.test(dat_imm$Score[dat_imm$Treatment == "Writing"])$statistic,
    shapiro.test(dat_imm$Score[dat_imm$Treatment == "Glossing"])$statistic
  ),
  p_value = c(
    shapiro.test(dat_imm$Score[dat_imm$Treatment == "Writing"])$p.value,
    shapiro.test(dat_imm$Score[dat_imm$Treatment == "Glossing"])$p.value
  )
) |>
  mutate(
    Decision = if_else(
      p_value > 0.05,
      "有意な逸脱は検出されない",
      "正規性からの逸脱が示唆される"
    ),
    across(c(W, p_value), \(x) round(x, 4))
  )

shapiro_tbl |>
  knitr::kable()
```

Shapiro-Wilk 検定は便利ですが、p 値だけで正規性を機械的に判定しない方が安全です。サンプルサイズが大きいと小さな逸脱でも有意になりやすく、逆に小さいと明らかな歪みを見逃すことがあります。だからこそ、QQ プロットとヒストグラムを併記します。

### 検定の実施

t 統計量は、平均値差をその標準誤差で割った値です。言い換えると、「群間差が、ばらつきを踏まえてどれだけ大きいか」を表しています。p 値はその t 値と自由度から計算されますが、p 値そのものは効果の大きさを示しません。したがって、平均値差の信頼区間と効果量をセットで読むことが重要です。

ここで、最初に理解すべき数量は 3 つあります。

- **平均値差**: 実際に何点違うのか
- **95%信頼区間**: その差をどの程度の幅で見積もるべきか
- **p 値**: 差が 0 だと仮定したときに、今回以上の結果がどれくらい珍しいか

この 3 つのうち、実際の教育研究で最も直感的なのは平均値差です。たとえば「平均で 2 点高い」はそのまま読み取れます。一方、効果量はその差を標準偏差で割った“比較しやすい尺度”、p 値はその差が偶然でも起こるかをみる尺度です。それぞれ役割が違います。

まず **Welch の t 検定だけを確実に理解すれば十分** です。Student の t 検定やノンパラメトリック検定は、「前提やデータの性質が違うときにどうするか」を知るための発展事項として読むと整理しやすくなります。

### 95%信頼区間をどう読むか

95%信頼区間は、「もっともらしい差の範囲」を表す区間です。今回の例では、平均値差の95%信頼区間はおよそ `r round(welch_result$conf.int[1], 2)` 点から `r round(welch_result$conf.int[2], 2)` 点です。つまり、Writing 群の優位性は 0 点差付近ではなく、少なくとも 1 点程度はありそうだ、と読みます。

ただし、95%信頼区間を「真の値が95%の確率でこの中にある」とそのまま言い換えるのは、頻度主義統計の厳密な言い方ではありません。正確には、「同じ手続きを何度も繰り返したとき、そのたびに作られる区間の 95% が真の値を含む」という意味です。それでも実務上は、「どれくらいの差がもっともらしいかを見る幅」と理解しておけば十分役に立ちます。

特に意識するとよいのは次の 2 点です。

- **区間が狭いほど** 推定は精密
- **区間が広いほど** 推定には不確実性が大きい

今回の章では p 値だけでなく、この信頼区間を必ず併記する方針をとっています。これは Cumming が強調する “new statistics” の考え方とも一致します [@cumming2014]。

この「95%」という言い方を直感的に理解するには、同じ条件で研究を何度も繰り返す場面を思い浮かべると役立ちます。下の図では、同じ母集団から 80 回研究を繰り返し、そのたびに平均値差の 95% 信頼区間を作っています。

```{r}
#| eval: true
#| label: fig-ci-coverage-visual
#| fig-width: 7
#| fig-height: 7
#| fig-cap: "95%信頼区間の長期的な被覆率"
#| fig-alt: "同じ条件で80回研究を繰り返したときの平均値差と95%信頼区間。真の差を含む区間は青、含まない区間は赤で示されている。"

true_p_glossing <- 0.54
true_p_writing <- 0.68
true_diff_ci <- 15 * (true_p_writing - true_p_glossing)
n_ci_demo <- 25
n_rep_ci <- 80
set.seed(202405)

ci_demo <- purrr::map_dfr(1:n_rep_ci, \(i) {
  writing_scores <- rbinom(n_ci_demo, size = 15, prob = true_p_writing)
  glossing_scores <- rbinom(n_ci_demo, size = 15, prob = true_p_glossing)
  ci_result <- t.test(writing_scores, glossing_scores)

  tibble(
    Study = i,
    Estimate = mean(writing_scores) - mean(glossing_scores),
    CI_low = ci_result$conf.int[1],
    CI_high = ci_result$conf.int[2],
    Covers = ci_result$conf.int[1] <= true_diff_ci &
      ci_result$conf.int[2] >= true_diff_ci
  )
}) |>
  mutate(Study = factor(Study, levels = rev(unique(Study))))

ggplot(ci_demo, aes(x = Estimate, y = Study, color = Covers)) +
  geom_vline(xintercept = true_diff_ci, linetype = "dashed", color = "grey40") +

    values = c(`TRUE` = "steelblue4", `FALSE` = "firebrick"),
    labels = c(`TRUE` = "Covers the true difference", `FALSE` = "Does not cover the true difference")

  labs(
    x = "Mean difference",
    y = "Repeated study",
    color = "",
    title = "What a 95% confidence interval means",
```

この図で青い区間は真の差を含んでおり、赤い区間は含んでいません。95% 信頼区間とは、「今作った 1 本の区間に 95% の確率で真の値が入る」という意味ではなく、**同じ手続きを何度も繰り返したとき、作られる区間の約 95% が真の値を含む**という長期的な性質を表しています。この例でも、80 本中 `r sum(ci_demo$Covers)` 本の区間が真の差を含んでいます。

#### サンプルサイズが増えると CI はどう変わるか

## t 検定と回帰分析のつながり

ここまで t 検定を 2 群比較として見てきました。ここで一度、t 検定が単回帰分析とどうつながるかを確認しておきます。

回帰分析は、一般に

$$
Y = b_0 + b_1 X + \varepsilon
$$

という形で表されます。`lm()` もこの形のモデルを当てはめる関数です [@rstatslm]。

- $X$ が連続変数なら、回帰直線は傾きをもつ通常の単回帰になります。
- $X$ が 0/1 の 2 値変数なら、$b_0$ は 0 群の平均、$b_1$ は 1 群と 0 群の平均値差になります。

つまり、**2 群の平均値差を調べる t 検定は、「説明変数が 2 水準だけの回帰分析」として書き直すことができます**。

```{r}
#| eval: true
#| label: fig-regression-connection
#| fig-width: 8
#| fig-height: 4.8
#| fig-cap: "単回帰と2群比較としての t 検定"
#| fig-alt: "左パネルは連続的なXに対する単回帰、右パネルはGlossingを0、Writingを1とした2値説明変数に対する回帰直線を示している。"

set.seed(202406)
regression_demo <- bind_rows(

  geom_smooth(method = "lm", se = FALSE, color = "steelblue", linewidth = 1) +

```

左の図は、普通の単回帰です。右の図では、`Glossing = 0`, `Writing = 1` と符号化すると、回帰直線は「2 群の平均を結ぶ線」になります。0 の位置の予測値が Glossing 群の平均、1 の位置の予測値が Writing 群の平均です。

この表から、**Student の t 検定と、0/1 に符号化した説明変数をもつ `lm()` は同じ平均値差・同じ t 値・同じ p 値を返す**ことがわかります。厳密に一致するのは等分散を仮定する Student の t 検定です。Welch の t 検定は、その考え方を保ったまま等分散を仮定しないように拡張したものです。

2 水準の要因に対する ANOVA の $F$ 検定は、この Student の t 検定を二乗したものとして理解できます。つまり、2 群比較で見ている平均値差の考え方は、第2章で扱う ANOVA やカテゴリカル変数のコーディングへそのままつながります。

この見方をもっておくと、t 検定、ANOVA、回帰分析が別々の道具に見えにくくなります。チュートリアル論文が強調する「推定量と不確実性を一貫して考える」という発想にもつながります [@cumming2014]。

## 効果量

p 値は「差があるか」を問う指標であり、「**差がどれくらい大きいか**」を直接は教えてくれません。t 検定の結果を報告するときは、効果量を合わせて示すことで、実質的な意味を読み取りやすくなります [@lakens2013]。近年の応用言語学では、p 値と効果量をセットで報告することが標準的な作法となりつつあります。

### 標準化効果量の種類

- Cohen's *d*: 平均値差をプールした標準偏差で割った値。最も基本的な標準化平均差です [@cohen1988]。
- Hedges' *g*: Cohen's *d* に小標本補正係数 $J(\nu) = \Gamma(\nu/2) / [\sqrt{\nu/2}\,\Gamma((\nu-1)/2)]$ (近似式 $J(\nu) \approx 1 - 3/(4\nu - 1)$) を掛けて、自由度 $\nu$ が小さいときの過大推定を抑えたもの [@hedges1981]。サンプルサイズが小さい研究やメタ分析でよく使われます。
- Glass's Δ: 対照群の標準偏差だけで標準化する指標 [@glass1976]。介入によって実験群の分散が変わる可能性があるときに、対照群の散らばりを基準として固定したい場合に有用です。

代表的な目安として、Cohen は $d = 0.2, 0.5, 0.8$ を small, medium, large と整理しました [@cohen1988]。ただし、Cohen 自身が「分野固有の根拠が得られないときに限って参照すべき**便宜的な定義** (operational definitions)」と注意していた点は強調しておく必要があります。文脈に即した解釈を置き換えるものではありません [@cohen1988; @lakens2013]。本章の検定力図では参考値として $d = 1.2$ も示しますが、Cohen の基本的な目安は次の 3 段階です。

| Cohen's *d* | 効果の大きさ |
|---|---|
| 0.2 | 小 |
| 0.5 | 中 |
| 0.8 | 大 |

: Cohen's *d* の便宜的な解釈目安 {#tbl-cohen-benchmarks}

#### 第二言語習得研究に固有の目安

応用言語学・SLA の文脈では、Cohen の目安は実態より厳しすぎるという指摘があります。Plonsky と Oswald は 346 本の L2 研究を集計し、**研究デザイン別の経験的な参照値**を提案しました [@plonsky2014]。

| 指標 | 小 | 中 | 大 |
|---|---|---|---|
| 群間 Cohen's *d* (between-groups) | 0.40 | 0.70 | 1.00 |
| 群内 Cohen's *d* (within-group) | 0.60 | 1.00 | 1.40 |
| 相関係数 *r* | 0.25 | 0.40 | 0.60 |

: Plonsky & Oswald (2014) による L2 研究の効果量参照値 {#tbl-plonsky-benchmarks}

群内 *d* (前後比較などの対応あり設計) が群間 *d* より大きく見積もられているのは、参加者内のばらつきが分母に入らない分、同じ介入でも値が大きく出やすいからです [@plonsky2014]。**SLA 系の論文では、Cohen の伝統的な目安より Plonsky & Oswald の参照値の方が研究実態に即している**と理解しておくと、報告時の解釈ぶれが減ります。

ただし、これらも分野平均を整理した「典型値」であって、固定的な合否基準ではありません。たとえば教育介入のコストや測定の精度を勘案すれば、$d = 0.30$ でも実務的に重要な差として扱う場面はあります。次節で見るように、近年は「**研究計画段階で『どの程度の差なら実務的に意味があるか』を事前に決める**」という発想 (smallest effect size of interest, SESOI) が推奨されています [@lakens2022sample]。

どの効果量を主に報告するかは、研究目的と分散の扱いによって変わります。

| 場面 | 主に使う指標 | 注意点 |
|---|---|---|
| 通常の独立 2 群比較 | Cohen's *d* または Hedges' *g* | どの標準偏差で割ったかを明記する |
| 小標本やメタ分析への再利用を重視 | Hedges' *g* | 小標本補正が入る |
| 対照群のばらつきを基準にしたい | Glass's Δ | 介入群の分散変化を標準化に含めない |
| 同一参加者の前後比較 | 対応あり *d* | 独立 2 群の *d* とは直接比較しない |

: 効果量選択の目安 {#tbl-effect-size-decision}

### 効果量の計算

`effectsize` パッケージは、Cohen's *d*, Hedges' *g*, Glass's Δ を同じ記法で計算でき、95% 信頼区間も併せて出力します [@effectsize]。ここでは `reference = "Glossing"` を明示し、正の値が「Writing 有利」を意味するように符号を固定します。Cohen's *d* はプールした標準偏差を分母にする記述的な標準化平均差なので、Welch の t 検定を主報告にする場合でも、平均値差とその CI を主に読み、標準化効果量は分母を明記して補助的に解釈します。

```{r}
#| eval: true
#| label: tbl-effect-size
#| tbl-cap: "Immediate recall の効果量比較"

cohens_result <- cohens_d(
  Score ~ Treatment,
  data = dat_imm,
  reference = "Glossing"
)
hedges_result <- hedges_g(
  Score ~ Treatment,
  data = dat_imm,
  reference = "Glossing"
)
glass_result <- glass_delta(
  Score ~ Treatment,
  data = dat_imm,
  reference = "Glossing"
)

tab_es_plot <- tibble(
  Measure = c("Cohen's d", "Hedges' g", "Glass's Δ"),
  Estimate = c(
    cohens_result$Cohens_d,
    hedges_result$Hedges_g,
    glass_result$Glass_delta
  ),
  CI_lower = c(
    cohens_result$CI_low,
    hedges_result$CI_low,
    glass_result$CI_low
  ),

    cohens_result$CI_high,
    hedges_result$CI_high,

  mutate(across(where(is.numeric), \(x) round(x, 2)))

tab_es |>
  knitr::kable()
```

Hedges' *g* が Cohen's *d* よりわずかに小さくなるのは、小標本補正が入るためです。サンプルサイズが十分大きければ、両者はほぼ同じ値になります。

この例を一文で言うと、**この差は統計的に有意なだけでなく、Cohen's *d* = `r round(cohens_result$Cohens_d, 2)` と、実質的にも無視しにくい大きさ**です。

ここまでで、平均値差にも Cohen's *d* にも信頼区間が付くことを見てきました。両者はどちらも大切ですが、答えている問いが少し違います。

したがって、教育研究では **平均値差の CI を主に読み、効果量の CI でその差の相対的な大きさを補う**、という順番で解釈するとわかりやすくなります。

### 対応ありデザインの効果量

ここまでは独立 2 群の効果量でした。もし同じ参加者を前後比較するなら、独立 2 群の *d* ではなく対応あり *d* を使います。`effectsize::cohens_d(..., paired = TRUE)` は、差得点の標準偏差で平均差を割る対応あり標準化平均差（しばしば $d_z$ と呼ばれる量）を返します。これは参加者内相関の影響を受けるため、独立 2 群のプール標準偏差による *d* とは直接比較しません。

### 効果量の変換

Cohen's *d* から相関係数 $r$ への変換は、次の式で表せます。

$$
r = \frac{d}{\sqrt{d^2 + a}}
$$

ここで $a = \frac{(n_1 + n_2)^2}{n_1 n_2}$ です。メタ分析のように研究間で指標をそろえたいときには、こうした変換式が役立ちます。研究統合では Hedges' *g* を報告しておくと再利用しやすくなります。

### 発展: ロバスト・ノンパラメトリックな効果量と Bayes 推定

通常の Cohen's *d* / Hedges' *g* は平均値と標準偏差に基づくため、外れ値や強い歪みがあると不安定になります。次の 4 系統が、近年のレビューでもよく言及される代替指標です。

::: {.callout-tip}
## 用途別の代替効果量

| 場面 | 推奨指標 | 主なR実装 |
|---|---|---|
| 外れ値や強い歪みがある | ロバスト標準化平均差 (トリム平均と Winsorized 分散を使う) | `WRS2::akp.effect()` [@algina2005; @wrs2pkg] |
| 順序データや中央値差として読みたい | 確率的優越性 (Probability of Superiority, $P(X > Y)$) ・Vargha-Delaney $\hat{A}$ | `effectsize::p_superiority()` [@vargha2000] |
| 効果量推定の信頼区間をブートストラップで | BCa CI を `boot::boot.ci()` 経由で算出 | `boot` + `effectsize::cohens_d()` の組み合わせ |
| 「差がない」という結論まで含めて主張したい | Bayes ファクターまたは事後分布による *d* 推定 | `BayesFactor::ttestBF()` [@rouder2009; @bayesfactorpkg], Kruschke の BEST 法 [@kruschke2013] |
:::

たとえば外れ値が結果を支配していそうな場合は、`WRS2::akp.effect(Score ~ Treatment, data = dat_imm, EQVAR = TRUE, tr = 0.2)` のようにトリム比 (`tr`) を指定したロバストな標準化差を併記すると、結果の頑健性が確認できます [@algina2005]。

確率的優越性 ($P(X > Y) + 0.5 P(X = Y)$) は、Common Language Effect Size と本質的に同じ量で、CLES が McGraw-Wong によって直感的解釈として提案された後 [@mcgraw1992]、Vargha と Delaney によって計算上の改良が加えられた指標です [@vargha2000]。順序データや非パラメトリック設計でも自然に解釈できる点が利点です。`effectsize::p_superiority(x, y, parametric = FALSE)` でノンパラメトリック版が直接得られます。

Bayes 系の代替手法 (Bayes ファクター、BEST 法など) は本書第 7 章で詳しく扱います。L2 研究での Bayes 法の応用例は @norouzian2018 が包括的です。

## 「有意差がない」と「等価である」は違う

「`p > .05` だったので差はなかった」という記述は、研究者が無意識に書いてしまいがちですが、統計的には正確ではありません。

通常の有意差検定では、帰無仮説は「差が 0」です。したがって、`p > .05` だったときに言えるのは、**「帰無仮説を棄却できなかった」** ということだけです。ここで「帰無仮説を採択した」「差がないことが証明された」とまでは言えません。

もし本当に主張したいことが「条件間に意味のある差はない」であれば、通常の t 検定ではなく **等価性検定**（equivalence testing）を使う必要があります [@lakens2018equiv]。

等価性検定では、発想が逆になります。

- 通常の有意差検定: 「差は 0」を出発点にして、それを棄却できるかを調べる。
- 等価性検定: 「差は無視できるほど小さくはない」を出発点にして、それを棄却できるかを調べる。

実務では、まず「どの程度までの差なら実質的に同じとみなすか」を **等価性境界**（equivalence bounds, SESOI: smallest effect size of interest）として事前に決めます。たとえば 15 点満点の再生テストなら、「平均差の絶対値が 1 点未満なら実務上は同じとみなす」という境界を置くことが考えられます。

TOST（two one-sided tests）では、$\alpha = .05$ の等価性検定において、90% 信頼区間がこの等価性境界の内側に完全に収まれば、「実質的に等価」と判断できます。通常の両側 5% 有意差検定では 95% 信頼区間が 0 を含むかどうかを見るため、ここで使う 90% 信頼区間とは役割が異なります。次の図は、その考え方を概念的に示したものです。

この図の読み方は次のとおりです。

- **差が明確に正方向**: この概念図では信頼区間が 0 から離れており、等価性境界の外側にあります。通常の両側 5% 有意差検定では、別途 95% 信頼区間または p 値で判断します。
- **結論保留**: 0 をまたいでいて、なおかつ等価性境界にも収まっていない。差があるとも、十分小さいとも言えない。
- **実質的に等価**: 90% 信頼区間が等価性境界の内側に完全に収まっている。差があっても、事前に決めた基準より小さいといえる。

要するに、**通常の t 検定で p > .05 だったからといって「差がない」とは言えません**。その主張をしたいなら、事前に「どれくらい小さければ同じとみなすか」を定め、等価性検定を別途行う必要があります。

## チュートリアル論文からの実務的なまとめ

この章で採用している方針は、近年のチュートリアル論文の勧めと整合するように組んでいます。

1. **p 値だけで終わらせず、効果量と信頼区間を必ず見る**。Lakens の実践的レビューや Cumming の “new statistics” は、この点を強く勧めています [@lakens2013; @cumming2014]。
2. **独立 2 群比較では Welch を標準とする**。Student の t 検定は等分散が強く妥当なときに限れば使えますが、実務上は Welch を主に使う方が安全です [@delacre2017]。
3. **p > .05 を「差がない」と読み替えない**。その主張には、等価性境界を事前に定めた等価性検定が必要です [@lakens2018equiv]。
4. **検定力は事後より事前に使う**。観測後の “observed power” より、計画段階での a priori power analysis の方が研究設計に役立ちます [@hoenig2001]。

この 4 点を理解しておくと、t 検定を単なる「p 値を出す手順」としてではなく、推定・不確実性・実質的重要性を含めた分析の入口として理解しやすくなります。

## サンプルサイズと検定力分析

研究計画の段階では、期待する効果量に対して **何人必要か**を見積もっておくことが、再現可能な研究のための第一歩になります。Lakens のサンプルサイズ正当化論文 [@lakens2022sample] は、伝統的な検定力分析にとどまらず、**実質的に意味のある最小効果量** (smallest effect size of interest, SESOI) を事前に決めて、その値に対して計画する発想を体系的に整理しています。L2 研究では、Plonsky & Oswald の参照値 [@plonsky2014] や先行メタ分析 (例: @norris2000) の効果量分布を起点に SESOI を設定する方法が現実的です。

R の公式ドキュメントにある `power.t.test()` は、平均値差 `delta` と標準偏差 `sd` を使って検定力計算を行います [@rstatspowerttest]。ここでは標準化効果量 $d$ を使いたいので、`sd = 1` と置き、`delta = d` として扱います。`type = "two.sample"` のとき、`n` は総サンプルサイズではなく **各群の人数**である点にご注意ください。

先ほど見たように、サンプルサイズが大きいほど信頼区間は狭くなります。検定力分析は、その同じ事実を「差を検出できる確率」という観点から見直したものです。

```{r}
#| eval: true
#| label: power-helper

power_from_d <- function(d, n = NULL, power = NULL, sig.level = 0.05,
                         type = "two.sample", alternative = "two.sided") {
  stats::power.t.test(
    n = n,
    delta = d,
    sd = 1,
    sig.level = sig.level,
    power = power,
    type = type,
    alternative = alternative
  )
}
```

事前の計画には有用ですが、観測された効果量をそのまま代入した「事後検定力」は新しい情報をほとんど増やしません [@hoenig2001]。そのため、ここでは a priori の検定力分析に絞ります。

ここも一文で言うと、**研究を始める前に「何人いれば差を見つけやすいか」を決めるのが検定力分析**です。

### 発展: シミュレーションで検定力を見積もる

`power.t.test()` は、標準化効果量を指定して素早く必要人数を見積もれる便利な関数です。一方、実際のテスト得点は 15 点満点のように上限と下限があり、必ずしも完全な正規分布にはなりません。そこで経験者向けには、**データを発生させる → t 検定を行う → 有意になった割合を数える** というシミュレーションも有用です。

考え方は単純です。たとえば「Glossing 群の正答確率が .62、Writing 群の正答確率が .72 なら、15 点満点では平均差が約 1.5 点になる」と仮定します。その仮定のもとで研究を何度も仮想的に繰り返し、どれくらいの割合で `p < .05` になるかを見ます。

```{r}
#| eval: true
#| label: simulation-helper

simulate_ttest_once <- function(n_per_group, p_glossing, p_writing,
                                n_items = 15, alpha = 0.05) {
  glossing_scores <- rbinom(n_per_group, size = n_items, prob = p_glossing)
  writing_scores <- rbinom(n_per_group, size = n_items, prob = p_writing)
  test_result <- t.test(writing_scores, glossing_scores)

  tibble(
    p_value = test_result$p.value,
    significant = test_result$p.value < alpha,
    mean_diff = mean(writing_scores) - mean(glossing_scores),
    ci_width = diff(test_result$conf.int)
  )
}

simulate_ttest_behavior <- function(n_per_group, p_glossing, p_writing,
                                    n_items = 15, nsim = 600,
                                    alpha = 0.05) {
  purrr::map_dfr(
    seq_len(nsim),
    \(i) simulate_ttest_once(
      n_per_group = n_per_group,
      p_glossing = p_glossing,
      p_writing = p_writing,
      n_items = n_items,
      alpha = alpha
    )
  ) |>
    summarise(
      rejection_rate = mean(significant),
      average_mean_diff = mean(mean_diff),
      average_ci_width = mean(ci_width),
      .groups = "drop"
    )
}
```

まず、差がない場合と差がある場合を比べます。差がない場合の棄却率は、第1種過誤率、つまり本当は差がないのに有意差ありと判断する割合に対応します。差がある場合の棄却率は、検定力に対応します。

## トラブルシューティング

t 検定を実際に使い始めると遭遇しやすい 5 つの状況について、原因と対処法を整理します。該当する項目だけ参照する形でも構いません。

### p 値は有意でも効果量が小さいときは?

「`p < .001` で有意な結果が出たのに、Cohen's *d* を計算したら 0.1 程度しかなく、解釈に困ってしまった」 — このような状況は、特にサンプルサイズが大きい研究で起こりやすいパターンです。

**原因:** サンプルサイズが大きいほど、ごくわずかな差でも p 値は小さくなります。これは検定の数学的性質であり、必ずしも実質的に意味のある差を反映しているわけではありません。

**対処:** p 値だけで結論を書かず、**効果量とその信頼区間を必ず併記する**のが安全です。「統計的に有意である」と「実質的に意味のある差である」は別物として扱う習慣をつけてください。

### 「`p > .05` だから差がない」と書きたくなったときは?

論文の Discussion で「群間に有意差は見られなかった (`p > .05`) ため、両条件は同等の効果を持つ」と書きたくなる場面があるかもしれません。しかしここは慎重に扱う必要があります。

**原因:** `p > .05` は「**差がないことの証明**」ではなく、「**差があるとは言い切れなかった**」という意味でしかありません。検定力不足で差が見えなかった可能性も含まれます。

**対処:** 本当に「条件間に意味のある差はない」と主張したいのであれば、通常の t 検定ではなく、本章の「[「有意差がない」と「等価である」は違う]」節で扱った **等価性検定**(等価性境界を事前に決めて行う検定)を採用するのがよいでしょう。

### 対応ありと対応なしを取り違えてしまったら?

同一参加者の Pre/Post を比較しているのに `paired = TRUE` を付け忘れる、あるいは逆に独立 2 群なのに対応ありで処理してしまう — これも初期にやりがちなミスです。

**原因:** 対応の有無を間違えると、標準誤差の計算が崩れ、p 値も信頼区間も信用できなくなります。

**対処:** データを目の前にして、まず **「同じ参加者 ID が両群に登場するか?」** を確認してみてください。登場するなら対応あり (`t.test(..., paired = TRUE)` および `cohens_d(..., paired = TRUE)`)、登場しないなら対応なしが原則です。

### 効果量や t 値の符号が逆になってしまうときは?

`cohens_d()` の出力符号が、自分の予想と逆になっていて戸惑った、という経験はありませんか? これは群の並び順が暗黙のうちに決まってしまうために起こります。

**原因:** R は要因の水準順序(アルファベット順がデフォルト)で「どちらを基準にするか」を勝手に決めます。そのため、どちらが正でどちらが負か、コードを見ただけでは分からなくなりがちです。

**対処:** 本章では `Writing - Glossing` が正になるように `forcats::fct_relevel()` で水準順を明示し、`cohens_d()` でも `reference = "Glossing"` を指定しました。**「どちらを基準に差を取ったか」を必ずコードと報告文の両方に明記してください。**

### 同じデータに何度も t 検定をかけたくなったら?

「3 群を 2 群ずつ全ペアで比較すれば 3 回の t 検定で済む」と考えてしまうのは自然な発想ですが、ここには **多重比較の罠**が潜んでいます。

**原因:** 複数回の検定を同じ有意水準 (α = .05) で行うと、**少なくとも 1 つで偽陽性が出る確率**は急速に上がります(α = .05 で 3 回なら約 14%)。

**対処:** 比較が複数あるなら、**ANOVA や混合効果モデル**で一度に扱う方が原理的に自然です(第 2・6 章を参照ください)。やむを得ず複数の t 検定を行う場合は、**Holm 法や Bonferroni 補正**などの多重比較調整を検討してください。`p.adjust()` 関数で簡単に補正できます。
