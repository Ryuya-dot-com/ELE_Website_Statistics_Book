0.1 主なパッケージの役割

  • ggplot2: 章冒頭で使う概念図や説明用の図を描画する。

はじめに

本書は、英語教育および第二言語習得（SLA）研究に携わる大学院生・研究者を対象に、統計解析の理論と実践をRで学ぶためのガイドです。研究論文で頻出する手法を体系的に取り上げ、各章の解析コードと再現に必要なパッケージ・実行環境の確認方法を提供しています。

公開レビュー版について

版識別：2026-09-05（HTML版）。内容を継続的に訂正・更新する教材です。

全26ページのHTML生成・構造を確認し、重点箇所では計算結果と説明・表示を照合しています。ただし、全章の全コードを同じ深さで検証したものではなく、PDF・EPUB版の確認も含みません。実研究に適用する際は、各例の前提、データ構造、推論・予測の対象、使用環境を確認してください。

誤記・実行エラー・説明の改善案は、GitHub Issuesへお寄せください。版識別、ページURL、節名、問題の内容を添えると確認しやすくなります。コードの問題にはR・パッケージのバージョンと最小再現例も添えてください。投稿は公開されるため、個人情報・未公開の研究データ・認証情報は含めないでください。

0.1.3 本書の読み方：手法名より研究上の問いから選ぶ

分析手法は、データの形式だけで決めるものではありません。最初に「何を推定・説明したいか」を定め、次に観測単位の依存、アウトカムの尺度、必要な不確実性評価を確認します。たとえば同じ正誤データでも、群差の説明、未知データの予測、介入の因果効果では読むべき章と評価基準が異なります。

次の順序で考えると、手法名から逆算する誤りを避けやすくなります。

  1. 問いを定める：記述、関連、予測、因果、測定、研究統合のどれか。
  2. 観測単位を確認する：独立か、同じ参加者・項目・学校を繰り返し測っているか。
  3. アウトカムを確認する：連続、2値、カウント、順序、潜在変数、時空間・ネットワーク構造のどれか。
  4. 推論の条件を確認する：欠測、外れ値、モデル診断、感度分析、一般化したい母集団を明示できるか。

手法選択で避けること

「連続変数だから t 検定」「有意にならなかったから別の手法」という選び方はしません。確証的分析では、主要な問い、推定対象、除外規則、モデル、評価指標をデータ確認前にできるだけ定め、結果が合理的な別仕様でも維持されるかを確認します。探索的分析は探索的であることを明示します。

0.1.4 構成

第I部：統計モデルの基礎

t検定、効果量、分散分析（ANOVA）、MANOVA、判別分析を扱います。カテゴリカル変数のコーディング方法についても詳しく解説します。

第II部：回帰分析

重回帰分析、交互作用の解釈（simple slopes / Johnson-Neyman）、一般化線形モデル（GLM）、一般化加法モデル（GAM）、混合効果モデル、2値ロジスティック回帰を扱います。

第III部：ベイズ統計と機械学習

brmsを用いたベイズ推定の基礎と、決定木・ランダムフォレスト・XGBoostによる予測分析、ROC曲線を用いたモデル評価を扱います。

第IV部：多変量解析

因子分析、主成分分析、コレスポンデンス分析、多次元尺度法、一般化可能性理論（G理論）、項目応答理論（IRT）、ラッシュモデル、拡張ラッシュモデルを扱います。

第V部：時系列データ分析

基礎章（ARIMA・ETS・介入時系列分析）、発展章（VAR・DTW・HMM・状態空間・ベイズ時系列）、音声章（Praat・rPraat・音響分析）の3章構成です。

第VI部：地理空間データ

sfパッケージによる地図作成の入門から、空間自己相関・空間回帰・施策評価の応用まで扱います。

第VII部：ネットワーク分析

学習者間・変数間の関係構造を可視化し、中心性指標やコミュニティ検出の手法を扱います。

第VIII部：メタ分析

研究成果の統合、異質性の評価、出版バイアスの検出、メタ回帰を扱います。

第IX部：因果推論とクラスタリング

統計的因果推論（潜在アウトカム、交絡調整、傾向スコア、DID）と、クラスタリング（k-means、階層クラスタリング、クラスタ解釈）を扱います。

第X部：欠測データ解析とロバスト統計

欠測メカニズム（MCAR/MAR/MNAR）に応じた処理、多重代入（MI）・FIML、そして外れ値や前提違反に対するロバスト統計を統合的に扱います。

#### 手法選択で避けること

「連続変数だから t 検定」「有意にならなかったから別の手法」という選び方はしません。確証的分析では、主要な問い、推定対象、除外規則、モデル、評価指標をデータ確認前にできるだけ定め、結果が合理的な別仕様でも維持されるかを確認します。探索的分析は探索的であることを明示します。
:::

### 構成

::: {.callout-note appearance="minimal"}
#### 第I部：統計モデルの基礎
t検定、効果量、分散分析（ANOVA）、MANOVA、判別分析を扱います。カテゴリカル変数のコーディング方法についても詳しく解説します。
:::

::: {.callout-note appearance="minimal"}
#### 第II部：回帰分析
重回帰分析、交互作用の解釈（simple slopes / Johnson-Neyman）、一般化線形モデル（GLM）、一般化加法モデル（GAM）、混合効果モデル、2値ロジスティック回帰を扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第III部：ベイズ統計と機械学習
brmsを用いたベイズ推定の基礎と、決定木・ランダムフォレスト・XGBoostによる予測分析、ROC曲線を用いたモデル評価を扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第IV部：多変量解析
因子分析、主成分分析、コレスポンデンス分析、多次元尺度法、一般化可能性理論（G理論）、項目応答理論（IRT）、ラッシュモデル、拡張ラッシュモデルを扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第V部：時系列データ分析
基礎章（ARIMA・ETS・介入時系列分析）、発展章（VAR・DTW・HMM・状態空間・ベイズ時系列）、音声章（Praat・rPraat・音響分析）の3章構成です。
:::

::: {.callout-note appearance="minimal"}
#### 第VI部：地理空間データ
sfパッケージによる地図作成の入門から、空間自己相関・空間回帰・施策評価の応用まで扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第VII部：ネットワーク分析
学習者間・変数間の関係構造を可視化し、中心性指標やコミュニティ検出の手法を扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第VIII部：メタ分析
研究成果の統合、異質性の評価、出版バイアスの検出、メタ回帰を扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第IX部：因果推論とクラスタリング
統計的因果推論（潜在アウトカム、交絡調整、傾向スコア、DID）と、クラスタリング（k-means、階層クラスタリング、クラスタ解釈）を扱います。
:::

::: {.callout-note appearance="minimal"}
#### 第X部：欠測データ解析とロバスト統計
欠測メカニズム（MCAR/MAR/MNAR）に応じた処理、多重代入（MI）・FIML、そして外れ値や前提違反に対するロバスト統計を統合的に扱います。
:::
